# Feature Audit Configuration Templates

本目录包含多预测期限特征审计（Multi-Horizon Feature Audit）模块的标准配置文件模板。

## 文件列表

- `audit_fu_10min_template.yaml`: 原生 10min 采样频率、七预测期限特征审计配置模板。
- `audit_fu_30min_template.yaml`: 原生 30min 采样频率、七预测期限特征审计配置模板。
- `comparison_fu_10min_vs_30min_template.yaml`: 10min 与 30min 匹配频率横向比对配置模板。
