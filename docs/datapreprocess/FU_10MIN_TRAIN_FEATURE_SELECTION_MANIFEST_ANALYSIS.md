## 一、任务背景与 Manifest 核心元数据概览

## 二、三流过滤淘汰漏斗全景追踪

在多合约评估中，566 个候选特征分别经过三个流独立的门禁流水线。由于各流的任务优化目标与数学约束不同，各门禁在三流中的淘汰规模呈现出高度分化的物理规律：

### 1. 三流逐级淘汰漏斗对照表

| 门禁阶段 (Filter Stage) | Slope VAE (趋势流) | Volatility VAE (波动流) | RL Decision (决策流) | 核心淘汰逻辑与物理归因 |
|---|---|---|---|---|
| **初始候选池 (Initial Pool)** | **566** | **566** | **566** | 基础 trades/quotes/orderbook/time/macro 候选特征池 |
| **流特定黑名单 (Stream Blacklist)** | 淘汰 **49** | 淘汰 **144** | 淘汰 **0** | Slope 排除纯波动率指标；Vol 排除有符号动量指标 |
| **分布漂移门禁 (Distribution Drift)** | 淘汰 **276** | 淘汰 **235** | 淘汰 **19** | VAE 设定极严漂移上限 (PSI <= 0.10/0.12)；RL 允许适度微观自适应 (PSI <= 0.45) |
| **硬预测相关性 (Hard Filter)** | 淘汰 **95** | 淘汰 **113** | 淘汰 **120** | Slope/RL 考量 RankIC (|r| >= 0.02/0.01)；Vol 考量绝对收益 VolRankIC (|r| >= 0.03) |
| **符号一致性 (Sign Consistency)** | 淘汰 **21** | 淘汰 **14** | 淘汰 **17** | VAE 要求 75% 合约同向；RL 要求 55% 合约同向 |
| **预测稳定性 (Stability IR)** | 淘汰 **14** | 淘汰 **0** | 淘汰 **6** | 考核 RankIC 跨合约均值相对标准差的信息比率 |
| **区制单调性 (Monotonicity)** | 淘汰 **28** | 淘汰 **34** | 不设限 (0) | Slope 要求 Down/Flat/Up 单调；Vol 要求 Low/Mid/High 严格递增 |
| **区制方差分析 (ANOVA F-Test)** | 淘汰 **5** | 不设限 (0) | 不设限 (0) | 检验宏观区制间特征均值差异的显著性 (F >= 4.0) |
| **正交聚类与去重 (Dedup / VIF)** | 淘汰 **64** | 淘汰 **15** | 淘汰 **276** | Ward 层次聚类压缩高共线性维度，保留各簇综合得分最高的代表特征 |
| **条件锚点挽救 (Conditional Anchors)**| 0 | 0 | 挽救 **3** | 将在极端空头高波分箱中具极高局部预测力的 3 个特征挽救入池 |
| **强制状态特征 (Mandatory Features)** | 引入 **1** (`trading_minute`) | 引入 **1** (`trading_minute`) | 引入 **17** (全量强制列) | 注入系统级不可剔除的时间进度与期限结构基准列 |
| **最终入选特征数 (Selected Total)** | **15** | **12** | **148** | **三流最终各自保留的特征维度** |

## 五、特征选择质量评估与下游架构影响

### 1. 对 Slope VAE 训练与潜在空间解耦的正面效应
- **零波动率污染**: 成功将 49 个标量波动率指标彻底隔离在 Slope VAE 之外，彻底消除了尺度方差对方向均值的稀释。
- **单调性与高 F-统计量**: 15 个入选特征（如 `bid3_price_trend_24`, `ask1_price_trend_2`, `rsv_48_std_norm_origin`）跨 Down/Flat/Up 均值严格单调且 ANOVA F 检验平均超越 4.0，使得高层 VAE 能够在潜空间 z_slope 中形成清晰对称的三峰聚类，赋予高阶路由高置信度的趋势判别边界。

### 2. 对 Volatility VAE 训练与 OOD 鲁棒性的保障
- **消除单边暴涨暴跌重构坍塌**: 144 个带符号方向性动量特征被严格屏蔽。12 个入选特征均为纯标量分散度（如 `bollinger_upper_6_origin`, `relative_volume_24`, `imin_16_origin`），其分布在上涨与下跌行情中保持一致的正半轴单峰形态，彻底根除了单边极端行情引发的重构误差异常飙升与虚假 OOD 熔断。
- **精准概率划分**: VolRankIC 达标特征使高层路由在 Low Vol 与 High Vol 之间形成清晰的概率间隔（`volatility_margin > 0.15`），使分级双重门控（Hierarchical Dual-Gating）能够稳健切换防御策略。

### 3. 对 RL 策略网络输入表征能力的增强
- **正交化与降维提效**: 从 566 个高维混杂候选特征中，通过 Ward 层次聚类将共线性特征压缩为 148 个正交代表特征（|r| <= 0.80, VIF <= 10.0），极大地改善了策略网络协方差矩阵的条件数，加速了 PPO/SAC 的梯度收敛。
- **条件锚点赋能极端行情生存**: 成功挽救 `trend_to_noise_96`, `trend_r2_48`, `log_return_vol_quantile_192` 等 3 个在极端行情中具备高预测力的稀缺特征，显著提升了底层 Agent 在暴跌高波行情中的下行风险抵御与回撤控制能力。
