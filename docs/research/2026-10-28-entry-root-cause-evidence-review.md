# “错误入场—退出—再次入场”根因证据审查

日期：2026-10-28。范围：只读源码和既有 valid 开发回放；没有读取 test、重跑训练或改生产代码。

后续进展：逐笔事件链和两条原路径的影子Q观察已完成，并复现一处多步TD折扣错误。止损后紧随的同向重开并非本段主要止损来源；更具体的线索是模型在浮亏时反复判断仍继续持仓。最新证据与限制见[根因追踪结果](2026-10-28-entry-root-cause-findings.md)。下文为前一轮审查时的判断。

## 结论先说

目前能确认的是一套会产生“持仓、平仓、以后再开仓”的状态机机制；**目前不能确认一条统一的“错误入场根因”**。特别是，亏损是在入场后才知道的结果，不能只凭最终亏损把当时决策称作可预见的错误。

基线中11个硬止损回合确实亏损约1,188.90元，但这是事后按退出原因统计；它说明硬止损回合是重要亏损来源，不证明模型在开仓时已有可靠信号可识别它们。入场研究里止损回合的Q差距中位数较低（3.29，对比赢家10.22），但基于该指标的真实策略回放反而变差，说明它尚未成为可靠的拒绝入场信号。[既有入场研究](2026-10-28-expert-hysteresis-entry-research.md#全局q门槛为什么失败)

## 源码确认的规则

1. **普通策略退出会允许以后重新入场。** 普通低层专家在实际推理时给出目标动作，flat 是正常动作之一；动作保持期间可能沿用此前动作。`get_action` 对非flat动作才启动动作保持，策略仍可以在之后给出flat退出。源码没有“普通策略一旦退出就禁止重新开仓”的永久规则。见 [`vae_routing_util.py`](../../FineFT/RL/DiHFT/high_level/vae_routing_util.py#L2045-L2065) 和 [`_arm_persistence`](../../FineFT/RL/DiHFT/high_level/vae_routing_util.py#L1631-L1635)。

2. **动作保持会短暂复用上一步的非flat动作。** 在保持步数用完前，系统可沿用原目标动作；如果该动作变得不可执行，就提前结束保持并重新推理。硬止损、某些防御动作和空模型状态也会清除保持计数。见 [`get_action` 动作保持分支](../../FineFT/RL/DiHFT/high_level/vae_routing_util.py#L2045-L2063)、[清除保持与硬止损](../../FineFT/RL/DiHFT/high_level/vae_routing_util.py#L1951-L1969)。所以动作保持是“多久重新问一次模型”的机制，不是独立的再次开仓信号。

3. **硬止损后会关闭仓位，并设置同方向冷却。** 达到配置的持仓收益率亏损阈值时，代码清空动作保持、记下止损方向并执行防御性平仓；随后在冷却期内，如果新动作仍想开同方向仓位，就拦截该动作。反方向动作不受这条“同方向”拦截。见 [硬止损分支](../../FineFT/RL/DiHFT/high_level/vae_routing_util.py#L1929-L1972) 和 [止损后同向拦截](../../FineFT/RL/DiHFT/high_level/vae_routing_util.py#L2099-L2123)。

4. **专家切换有自己的迟滞状态。** 专家门控可以进入防御状态或切换专家；防御分支可能按规则平仓或持有当前仓位。它与低层策略选flat/开仓、硬止损冷却是不同机制。已有入场特征中，11个止损回合仅1个标记为 `expert_replaced`、1个为 `switch_confirmation`；这不支持把基线的大多数止损简单解释成“专家频繁换人导致”。[特征汇总](2026-10-28-expert-hysteresis-entry-research.md#原11笔止损的入场事实)

5. **“浮盈保护退出”是研究候选，不是基线规则。** 研究版在浮盈达到名义金额1%后，若回吐至峰值一半以下且原策略仍持同向，才额外发出平仓；退出后仍可由原路由再次开仓。这个对照不能当作基线里存在追踪止盈。[规则定义](fu_10min_entry_20261028/profit_protection_probe/protection_definition.json)

## 既有回放支持什么、不支持什么

- 基线6,000元本金，净利润2,080.74元、步级最大回撤4.466%；75个平仓回合中11个以硬止损结束，止损回合净额-1,188.90元。参见[回放表](fu_10min_entry_20261028/all_replays.csv)。
- 把同向动量作为“更好入场”过滤器，三种窗口都让真实总收益变差；简单斜率同向也变差。它只否定这些具体过滤方案在本段 valid 上的效果，不能证明所有趋势过滤无效。[11组状态机回放](2026-10-28-expert-hysteresis-entry-research.md#已运行的真实状态机消融)
- 把止损后的同方向冷却从12步加到24步，只增加20.87元，止损回合数仍是11，MDD不变；延长到48步反而少赚80.26元，并多出1个止损回合。这说明“冷却短是主要根因”目前没有证据支持。回放中24步方案的增益集中于fu2509，并非跨合约普遍改善。[逐合约结果](fu_10min_entry_20261028/cooldown_24_contracts.csv)
- 浮盈1%后回吐一半就退出，胜率从56%升到67.9%，但净利润从2,080.74降至1,239.33元，MDD升至6.86%。这说明更早退出、胜率更高，不等于总收益更好；并且它没有提供“原亏损入场可提前识别”的证据。[回放汇总](2026-10-28-expert-hysteresis-entry-research.md#已运行的真实状态机消融)
- 全局Q差距门槛的真实回放净利润下降、MDD上升，并改变后续交易路径：一些原止损入场消失，同时出现新的止损入场。因此不能将原有亏损交易逐笔删除后，直接把静态差额当作可避免损失。[Q门槛回放](2026-10-28-expert-hysteresis-entry-research.md#全局q门槛为什么失败)

## 仍未证实的解释

以下解释都可能成为研究假设，但当前证据不足以把它们称为根因：模型缺少趋势确认、入场时机过早、退出后很快同向重开、专家交接造成反复交易、或者硬止损阈值太紧。源码只证明相应机制或阈值存在；现有消融没有逐个隔离出“退出—等待—再入场”链条的净因果效应。

尤其是，已有统计聚焦“每个回合的入场特征”和整体策略指标，未建立对所有止损前后重开事件的逐事件因果审计（例如确认同一合约、同一方向、止损时间、冷却拦截、再次开仓之间的精确间隔，并与不重开的反事实路径比较）。因此，当前最准确的说法是：**反复开仓是允许发生的状态机行为；它是否造成了主要亏损、哪些再入场本可避免，尚未被本轮证据回答。**

## 下一次要回答“根因”需要什么证据

以真实事件顺序构造每条链：开仓时可见信息与所选动作、持仓中策略为何转flat、是否硬止损、同方向冷却拦截了几次、下一次同方向开仓间隔、手续费和该链净额。再用一项预先写明的规则重放完整账户状态；不能只从已发生的亏损交易中挑掉几笔。规则须在未参与调参的时间段验证，否则同一valid上的反复筛选容易挑中偶然好运的路径。

当前建议面向用户的准确解释：**“我们能指出亏损主要落在硬止损回合，也知道止损后系统会短暂拦同方向重开；但现有试验没有证明亏损是因为重开太快，更没有证明这些亏损在入场时本来可以预测。要找根因，下一步需要把每次平仓和下一次开仓连成事件链，再在新时间段验证规则。”**
