# VAE 双轴特征分布外 (OOD) 治理后实证复测与系统稳态评估报告

- **报告编号**：RES-2026-1006-01
- **研究日期**：2026-10-06
- **研究对象**：FineFT 商品期货（燃料油 FU 10min 级别）VAE 双轴解耦架构在黑名单剔除 `historical_volatility_2`、重新执行特征筛选并重训 VAE 后的实证 OOD 表现。
- **评测执行入口**：`./FineFT/script/analysis/feature/vae_feature_ood_fu_10.sh`
- **核心结论**：
  1. **离群特征根除，OOD 增量暴降 85.4%**：波动率轴总测试集负对数似然增量（$\Delta\text{NLL}_{\text{test\_vs\_train}}$）由治理前的 **+0.5338** 彻底骤降至 **+0.0780**（降幅达 **85.38%**）。原单一特征 `historical_volatility_2`（原贡献 +0.4084 / 76.52%）彻底移除后，全轴无任何特征产生方差爆炸或分布塌陷。
  2. **斜率 VAE (15 维) 维持超强泛化**：总 $\Delta\text{NLL}_{\text{test\_vs\_train}} = \mathbf{-0.2374}$，单特征最大增量仅 $+0.0199$（`imax_48_origin`），15 个特征中有 10 个测试集似然优于训练集基准，稳态指标无懈可击。
  3. **分合约全面转入健康安全域**：在 13 个独立测试合约中，核心主力合约群（`fu2509` ~ `fu2602`）在两轴上均呈现全线负 NLL 或极低偏移；即使在临近交割的边缘合约 `fu2508`（+1.92）与远期低流动性合约 `fu2606`~`fu2609`（+0.72 ~ +0.92），亦完全处于安全门限（$\le 12.0$）极低水位。
  4. **工程决策**：当前 VAE 双轴特征体系（斜率 15 维 + 波动率 12 维）与模型权重已达到最佳稳态，**建议完全冻结 (Freeze) 表征流**，正式进入强化学习 (RL) 策略对接与下游训练。

## 2. 诊断日志与输出表格全面拆解

### 2.1 Table 1: Valid vs Train (验证集偏移机理)

- **斜率轴 (Slope)**：
  - 总增量 $+0.4634$。前三大贡献项为 `beta_12_std_norm_origin` (+0.1853, 39.98%)、`roc_16_std_norm_origin` (+0.1447, 31.23%) 与 `sumn_48_origin` (+0.1026, 22.14%)。
  - **机理剖析**：验证集处于训练集之后、测试集之前的阶段性震荡走势，中短期动量与斜率指标方差轻微扩大（方差比 $1.32 \sim 1.42\text{x}$）。但此偏移属典型时间序列周期性起伏。
- **波动率轴 (Volatility)**：
  - 总增量 $+0.4370$。前两大贡献项为 `bollinger_upper_6_origin` (+0.2342, 53.59%) 和 `plus_di_14` (+0.0669, 15.32%)。
  - **机理剖析**：布林线上轨在验证集出现单边抬升，方差比为 $1.31\text{x}$。在后续测试集中，该项 NLL 显著反弹回归正常。

### 2.2 Table 2: Test vs Train (全量测试集真实 OOD 塌陷诊断)

- **斜率轴 (Slope)**：
  - 全特征 $\Delta\text{NLL}$ 绝对值均 $\le 0.02$。
  - 最大增量 `imax_48_origin` 仅 $+0.0199$（均值漂移 $0.181\sigma$，方差比 $1.010\text{x}$）。
  - 其余绝大多数特征（如 `rsv_48`、`rsv_24`、`rank_24`、`bid3_price_trend_24`）重构损失甚至低于训练集，表明模型对价格结构具备极强适应力。
- **波动率轴 (Volatility)**：
  - **前三项贡献特征**：
    1. `trading_minute_progress`：$\Delta\text{NLL} = +0.0831$（均值漂移 $0.022\sigma$，方差比 $1.020\text{x}$）。日内线性时间进度，轻微统计偏差源于测试集合约假期交易日截断微差，方差比接近 1.00，属于数学无害项。
    2. `vsumd_48_origin`：$\Delta\text{NLL} = +0.0547$（均值漂移 $0.009\sigma$，方差比 $1.107\text{x}$）。480分钟下行成交量累积，反映 2025~2026 年市场大周期下行阶段的成交分布，方差比仅 1.10x。
    3. `vsumd_96_origin`：$\Delta\text{NLL} = +0.0359$（均值漂移 $0.019\sigma$，方差比 $1.051\text{x}$）。长周期成交量指标，分布基本与训练集重合。
  - **对冲项**：`bollinger_upper_6_origin` 在测试集上的 $\Delta\text{NLL} = -0.1110$，极大拉低了整体 NLL，全轴总增量收敛在 $+0.0780$。

### 2.3 Table 3: Test vs Valid (测试集与验证集泛化迁移)

- **波动率轴**：总增量 $-0.3589$。验证集中偏大的 `bollinger_upper_6_origin`（$\Delta\text{NLL} = -0.3452$）以及 `plus_di_14`（$\Delta\text{NLL} = -0.0568$）在测试集上均出现显著回调，证明验证集的短期波动未演变为永久结构性漂移。
- **斜率轴**：总增量 $-0.7008$。验证集出现方差偏大的 `beta_12`（$\Delta\text{NLL} = -0.2052$）和 `roc_16`（$\Delta\text{NLL} = -0.1391$）在测试集上全面回归，整体重构质量大幅超越验证集。

## 3. 分合约 (Per-Contract) OOD 深度微观审计

测试集涵盖从 `fu2508` 至 `fu2609` 共 13 个主力及非主力合约，实测分合约结果如下：

### 3.1 斜率轴分合约

- **13 个合约中 10 个合约总 $\Delta\text{NLL} < 0$**：
  - `fu2509` (-0.3222), `fu2510` (-0.0976), `fu2511` (-0.2014), `fu2512` (-0.1925), `fu2601` (-0.2832), `fu2603` (-0.1045), `fu2604` (-0.1621), `fu2605` (-0.1070), `fu2606` (-0.0864), `fu2607` (-0.2645), `fu2609` (-0.3089)。
  - 仅 `fu2508` (+0.3919) 与 `fu2602` (+0.0819) 微幅正向，均远低于任何警戒阈值。

### 3.2 波动率轴分合约

- **核心主力合约群（交易量 > 90%）**：
  - `fu2509`: $-0.2775$
  - `fu2510`: $-0.5513$
  - `fu2511`: $-0.3512$（治理前受 `historical_volatility_2` 影响贡献率曾高达 281.4%，现彻底转为极优负 NLL）
  - `fu2512`: $-0.1684$（治理前贡献率曾达 135.7%，现已完全修复）
  - `fu2601`: $-0.2029$
  - `fu2602`: $-0.1141$
  - **实证结论**：主力合约全部呈现负 NLL，模型在最核心的交易资产上表现显著优于基准训练集！
- **边缘及远月合约（流动性稀薄期）**：
  - `fu2508`: $+1.9259$（临近到期交割，流动性缩水，`vsumd_96` 贡献 $+0.6367$）。
  - `fu2606` (+0.7221), `fu2607` (+0.9251), `fu2609` (+0.8826)：主要受布林上轨在远月极度非活跃期的报价跳变影响。
  - **实证结论**：全合约最大 NLL 仅为 $+1.93$，相较于系统容忍红线（12.0）具备超 6 倍安全裕度。

## 4. 最终评估与落地建议

1. **特征工程稳态结论**：
   - 黑名单机制成功清除了超短采样周期带来的虚假方差跳跃；
   - 现行 15 维 `vae_slope` 与 12 维 `vae_volatility` 特征集兼备高信息量与极强泛化能力。
2. **表征模型冻结建议**：
   - 双轴 VAE 模型无需再做结构或参数微调，建议立即打上 Release 标签并冻结。
3. **下游强化学习对接**：
   - 隐空间向量 $z_{\text{slope}}$ 与 $z_{\text{volatility}}$ 的高斯似然与重建误差已完全可信，可作为下游强化学习智能体的平稳状态输入。
