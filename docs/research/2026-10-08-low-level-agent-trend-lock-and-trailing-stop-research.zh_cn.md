# Low-Level Agent 强趋势单向开仓硬锁与移动追踪止盈缺失的数学、物理与架构根因研究

- **研究主题**：为什么底层强化学习 Agent 无法自发学会“强趋势单向开仓硬锁”与“移动追踪止盈”？
- **归档日期**：2026-10-08
- **研究员**：AI Research Agent
- **关联代码与配置**：
  - 特征集：`dataset/10min/fu/rl_state_features.npy` (148 维微观因子)
  - 环境定义：`FineFT/env/env_class/base_env.py` (`trading_info` & `step` 计算)
  - 专家表算法：`FineFT/env/env_class/futures_util.py` (`create_optimal_q_table_from_df`)
  - 低层训练脚本：`FineFT/script/train/train_commodity_fu_10.sh` (`parallel_weight_advantage_pretrain.py`)
  - 执行引擎：`FineFT/RL/DiHFT/high_level/vae_routing_util.py` (`get_action` & `predict_action`)
- **关联架构决策**：ADR 0002, ADR 0037, ADR 0041, ADR 0045, ADR 0047, ADR 0048, ADR 0049, ADR 0050

## 1. 问题背景与实证现象 (Empirical Motivation)

在 2026-10-08 最新的燃料油 10 分钟验证集回测（`fu/10min_parallel`，Trial 200）中，策略总体取得了 **100% 胜率（12/12 盈利）**、**摩擦吞噬率降至 12.9%** 的突破。然而在 2,800 步以上的长周期核心主力合约中，暴露出了两大制约盈利进一步爆发的核心瓶颈：

1. **强趋势中的逆势摸顶与抄底（缺乏强趋势单向开仓硬锁）**：
   - 在 `fu2503` 持续 4 个月的单边大牛市（标的大涨 +36.72%）中，策略依然进行了 17.9%（692 步）的逆势做空尝试，**逆势做空直接造成 -126.0 点的纯利润亏损**；
   - 在 `fu2501` 前半程大跌 600 点（-18.9%）的深 V 行情中，策略反复尝试逆势抄底做多，触发了全周期最高的 **15 次硬止损** 和 **504 步断路器冷冻**，摩擦损耗高达 199 元（吞噬率 67.9%），最终净利仅微赚 +1.57%。
2. **大过山车行情中的利润大幅回吐（缺乏移动追踪止盈）**：
   - 在 `fu2505` 接近 8 个月（4,764 步）的漫长走势中，标的价格从 2,956 冲顶至 3,600 点（+21.8%），随后阴跌暴跌回落至 2,771 点；
   - 策略在第 3,041 步（3,600 顶部附近）时，**累计浮盈曾高达 `+697.56` 元（回报率 +11.63%）**；
   - 但策略在此后持续死扛多头达 71.6% 步数，平均持仓时长达 140 步，未能及时止盈离场，**硬生生回吐了 358.39 元（回吐了 51.4% 的历史最高利润）**，最终收盘仅留存 +339.17 元（+5.65%）。

用户与研究者很自然会提出疑问：**“既然底层强化学习 Agent 训练了数十万步，为什么它没有自主学会‘牛市绝不做空、熊市绝不做多’的硬锁，以及‘见好就收、高位回撤保盈’的移动止盈？”**

深入底层算法后，结论十分明确：**并非模型训练不足，而是底层 MDP 表征、时间尺度、DP 示范假设与奖励函数形式在数学和物理层面使得 Agent 根本不可能自主学出这两种行为。**

## 2. 强趋势单向开仓硬锁缺失的四大深层根因

### 2.1 特征工程的时间尺度严重短视（宏观视野物理盲区）
- **因子时间尺度审查**：
  查阅 `dataset/10min/fu/rl_state_features.npy` 中 Low-Level Agent 输入的 148 个特征：
  - 核心因子为：`roc_96`, `ma_12`, `min_24`, `pivot_pp_96`, `sumn_12`, `realized_volatility_12` 等；
  - 整个特征集中，**最长的时间窗口仅仅只有 96 根 K 线**（大部分为 2/6/12/24 步）。
- **时间跨度物理换算**：
  在 10 分钟 K 线下，96 步仅相当于 **16 小时（不到 3 个完整交易日）**！
- **盲区推论**：
  像 `fu2503`（单边上涨 4 个月）或 `fu2509`（单边暴跌 3 个月），其宏观趋势跨度长达 3,500 ~ 4,000 步。
  **Low-Level Agent 的观测输入完全没有跨月级别的长趋势因子**。当大牛市中出现一次持续 2~3 小时、幅度 30~50 点的技术性微观急跌时，在 Agent 只有 16 小时的小世界里，这就是一个胜率极高的“做空套利波段”。它根本不知道自己身处在轰轰烈烈的 4 个月大牛市之中。

### 2.2 分层架构的信息解耦：高层宏观体制对低层是完全黑盒的
- **架构决策依据**：
  根据 ADR 0037 和 ADR 0041，FineFT 为避免过拟合，严格实施了**高层 VAE 与低层 RL Agent 的特征双流/三流解耦**。
- **信息割裂现实**：
  - 高层 VAE 路由器拥有 132/147 步的长窗口动量与波动率特征，配合衰减因子 $\gamma=0.936$，能够精准划分出九宫格体制（例如 Slot 8 为“高波强牛”、Slot 6 为“高波强熊”）；
  - **但是，高层的体制分类结果（`regime_grid_id` 或 `slot_id`）并没有作为状态变量输入给底层 Q-Net！**
  - 底层 Q-Net 在前向计算时，接收的只有局部技术指标与单笔持仓状态 `trading_info`。
  - **Agent 根本不知道自己当前正被运行在 Slot 8 下**。它没有全局上下文输入，因此不可能在神经网络内部形成形如 `if regime == BULL: Q(short) = -inf` 的条件分支。

### 2.3 离线 DP 专家表的“上帝视角套利（Oracle Bias）”误导
- **离线预训练机制**：
  低层 Q-Net 在强化学习探索前，必须先在离线动态规划最优 Q 表（`create_optimal_q_table_from_df`）上进行 Warmup 预训练以稳定策略。
- **DP 算法的数学假设**：
  审查 `futures_util.py:1452-1622`，动态规划是通过**对全时序价格数组的反向逆序递推（Backward Induction）**求得的：
  $$Q^*(t, a, a') = r(t, a, a') + \gamma \max_{a''} Q^*(t+1, a', a'')$$
  **DP 算法拥有完全预知未来的“上帝视角（Oracle）”**！
- **专家示范的严重误导**：
  在真实历史大牛市中，只要某天夜盘价格回调了 30 点，DP 凭借上帝视角必然会在波峰最高那 1 根 K 线精准做空、并在回调最低点精准平仓翻多！
  **DP 专家展现给 Low-Level Agent 的行为模式是：“哪怕是超级大牛市，只要有 2 小时的微幅回调，你也要大胆做空！”**
- **实盘灾难**：
  实盘中的 Low-Level Agent 并没有上帝视角。当它试图模仿 DP 老师去逆势做空时，往往在牛市中途遭遇暴力反包逼空，导致 `fu2503` 逆势做空亏损 126 点。

### 2.4 高层执行层缺乏物理动作掩码（Action Masking 缺失）
- **代码物理审查**：
  审查 `vae_routing_util.py:1454-1463`：
  ```python
  actions_value = self.low_level_network(
      state=state,
      time=time_input,
      previous_action=previous_action,
      avaliable_action=avaliable_action,
      trading_info=trading_info,
  )
  action_value_chosen_index = actions_value[:, self.selected_agent_index, :]
  action = torch.max(action_value_chosen_index, 1)[1].data.cpu().numpy()
  ```
- **职责真空**：
  高层 VAE 虽然判定了 Slot 8（强牛体制），但在调用低层网络时，`avaliable_action` 并没有屏蔽做空动作！系统直接执行全部 3 个动作（做空、观望、做多）的 `argmax`。
  **高层信任所选的专家模型不会乱动，而底层模型却根据 10 分钟局部杂波发出了做空信号**，两者之间缺乏一道“物理动作掩码”。

## 3. 移动追踪止盈缺失的四大深层根因

### 3.1 状态空间缺乏“相对高水位回撤”的关键表征（马尔可夫盲区）
- **移动追踪止盈的数学定义**：
  $$\text{Drawdown from High Watermark} = \max_{\tau \in [t_{\text{entry}}, t]} \text{PnL}_{\tau} - \text{PnL}_t$$
  当且仅当利润从历史最高峰值回撤超过给定比例时触发离场。
- **代码物理审查**：
  在 `base_env.py:238-245` 中，环境向智能体输入的 `trading_info` 仅包含 4 个物理量：
  ```python
  return np.array([
      position_exposure,
      float(self.single_holding_return_rate),
      float(self.single_holding_max_drawdown),
      duration_norm,
  ], dtype=np.float32)
  ```
  - **严重混淆的概念**：这里的 `single_holding_max_drawdown` 计算的是**相对于开仓资金的最大亏损深度（Loss from Baseline Capital）**，而不是**相对于浮盈历史峰值的高水位回吐（Retracement from Peak）**！
  - **盲区场景**：在 `fu2505` 中，浮盈从最高 +697 点跌落到 +339 点时，账户依然是盈利的（`single_holding_return_rate > 0`）。在环境计算逻辑中，`drawdown` 指标根本没有向模型发出“浮盈已经回吐过半”的危机警报！
  - **前馈网络记忆缺失**：低层 Q-Net 采用前馈 MLP 架构（无 LSTM/Transformer 循环隐藏状态），网络无法记住“我曾经到过 697 元”的路径依赖历史。对 Agent 而言，当前赚 339 元就是它的全部认知。

### 3.2 RL 折扣累积奖励函数的数学本质：对“利润路径”完全不敏感
- **强化学习优化目标**：
  智能体通过策略梯度或 Q-Learning 最大化折扣回报期望：
  $$J(\pi) = \mathbb{E}\left[ \sum_{t=0}^T \gamma^t r_t \right]$$
  环境单步奖励为：
  $$r_t = \text{position}_t \times (P_t - P_{t-1}) - \text{friction}_t - \text{turnover\_penalty}_t$$
- **致命数学盲区**：
  由于期望算子和求和算子是线性的，**强化学习的目标函数只关心最终累加了多少钱，对过程中的资产路径形态完全无感**！
  - **路径 A（稳健单调上升）**：$0 \to 100 \to 200 \to 340$（总奖励约 340）；
  - **路径 B（坐剧烈过山车）**：$0 \to 300 \to 700 \to 340$（总奖励也是约 340）。
  - **惩罚真空**：环境**从未对“从最高点大幅回吐利润”扣减过哪怕 1 个单位的惩罚项（No Drawdown/Retracement Penalty）**。
  - 既然在 700 跌回 340 的过程中模型没有受到任何负反馈，在它的数学价值体系里，坐电梯和直达终点毫无区别，它自然没有动力去学“在 700 处保盈离场”。

### 3.3 动态规划 Q 表中根本不存在“回撤止盈”的样本示范
- **DP 专家的离散最优性**：
  在离线 DP 表的推导中，由于 DP 能预知未来价格，在价格到达绝对最高点（3,600 点）的**那一瞬间**，DP 会直接下达平仓指令。
- **样本结构差异**：
  - 人类与量化规则的移动止盈：**在最高点 3,600 之后，回撤 20%（跌到 3,450）才触发止盈**；
  - DP 专家的神仙操作：**在最高点 3,600 点顶峰直接平仓，回撤为 0%**。
- **示范缺失推论**：
  **在整个 DP 预训练经验池中，根本就不存在“在价格回撤后触发平仓”的有效轨迹！**
  当实盘中行情跌破 3,600 时，处于 3,450 点位的 Agent 根本没有学习过这种回撤出场的行为模式。它根据技术指标误以为这只是上升途中的一次短暂震荡，选择继续死拿。

### 3.4 ADR 0050 逆势调仓惩罚与 ADR 0049 迟滞带的“过度钝化副作用”
- 在最近的优化中，为了将此前 96.87% 的恶性摩擦吞噬彻底压制，我们引入了：
  - 门控平仓迟滞比率 $\alpha_{\text{exit}} = 0.64$（放宽了平仓退出条件）；
  - 非对称换手阻尼惩罚（逆势早退平仓施加 6 倍阻尼惩罚）。
- **两面性实证**：
  这两项机制在抑制无效换手上极其卓越（换手倍数从 722x 暴降至 16.4x），但**负面作用是让 Agent 在大趋势冲顶后变得“过度迟钝、不敢主动平仓”**！
  在 `fu2505` 见顶后，平仓出场需要承受 6 倍名义货值惩罚，且高层门控容忍度放宽，导致多头持仓被牢牢“锁死”，最终眼睁睁看着 51.4% 的浮盈蒸发殆尽。

## 5. 架构与工程层面的系统性根治方案 (Architecture Solutions)

现代量化系统与深度强化学习工程界的核心共识是：**“不要强求黑盒 RL 智能体用 16 小时的局部视界和前馈网络去学习全局时序的风控法则，而应该由外层的风控与门控架构进行显式约束”**。

针对上述根因，提出如下三项精准解药：

### 5.1 解药一：高层架构级动作掩码（Trend Action Masking in Gating）
- **定位**：解决“强趋势单向开仓硬锁”问题。
- **机制设计**：
  在 `vae_routing_util.py:predict_action` 中，根据高层 VAE 当前选定的 Regime Slot 对底层动作空间施加硬掩码（Action Masking）：
  - 当高层处于 **Slot 8（高波强牛）** 或 **Slot 2（低波强牛）** 时：
    将 `avaliable_action` 中的 **Short 动作置为 0（物理屏蔽）**，底层无论如何不能发出做空指令；
  - 当高层处于 **Slot 6（高波强熊）** 或 **Slot 0（低波强熊）** 时：
    将 `avaliable_action` 中的 **Long 动作置为 0（物理屏蔽）**，底层无论如何不能发出做多指令；
  - 震荡槽位（Slot 1, 4, 7）保持双向放行。
- **预期收益**：
  直接消除 `fu2503` 的 126 点逆势做空亏损，彻底根绝 `fu2501` 在单边大跌中连续 15 次盲目抄底硬止损的灾难。

### 5.2 解药二：执行层移动追踪止盈引擎（Tier 1 Trailing Profit Stop Engine）
- **定位**：解决“坐过山车、高位回吐利润”问题。
- **机制设计**：
  在 `vae_routing_util.py` 的风控执行流水线中，新增**高水位回撤追踪器（High-Water-Mark Tracker）**：
  1. **跟踪持仓峰值**：当持仓不为 0 时，每个 step 维护当前持仓的历史最高收益率 $R_{\max} = \max_{\tau \le t} \text{Return}_{\tau}$；
  2. **激活条件**：当 $R_{\max} \ge 8.0\%$（或浮盈超过 250 点）时，进入“移动止盈保护状态”；
  3. **破位止盈平仓**：一旦当前浮盈跌落至峰值的 $75\%$ 以下（即利润回吐超过 $25\%$），立即触发强平指令：
     - 指令原因标记为 `ActionDecisionReasons.TRAILING_PROFIT_STOP`；
     - 强制平仓归零，打断当前的 `action_persistence` 锁定；
     - 赋予单向短暂保护期，防止刚止盈又立即追高进场。
- **预期收益**：
  在 `fu2505` 中，浮盈在 3,600 点达到 697 元峰值后，一旦在 3,450 处回吐至 520 元立即强制保盈清仓，**直接为该合约锁死 +8.7% 以上的回报率，杜绝 358 点的大幅回吐**。

### 5.3 解药三：解除 0.45x 真实杠杆枷锁（动态仓位与持仓上限放开）
- **定位**：解决“赚到了全部点位，但资金回报率被 6,000 元分母稀释”的问题。
- **机制设计**：
  - 现有脚本 `--max_holding_number 1`，在 6,000 元账户里买 1 手 2,700~3,000 元的合约，真实名义杠杆仅 0.45x，资金闲置率高达 55%；
  - 将 `--max_holding_number` 放开至 **`2`**（或在 Slot 8 / Slot 6 强趋势槽位激活时允许加至 2 手）；
  - 真实杠杆恢复至 0.9x ~ 1.0x（健康无风险水平）。
- **预期收益**：
  - `fu2509` 当前收益率 +12.22%，2 手持仓将直接跃升至 **+24.4%**；

## 6. 强化学习框架内部的原生理论解决方案 (Native RL Theoretical Solutions)

除了第 5 节提出的外挂工程约束（高层动作掩码与三级风控拦截），强化学习（RL）框架本身**完全有一套数学完备、算法自洽的理论方案**来在模型内部根除这四大缺陷。

现代量化 RL（FinRL）与通用强化学习（如 DeepMind AlphaStar、机器人控制 Privileged Learning）针对类似瓶颈，在**状态空间表征（State）、网络骨干架构（Network）、目标奖励函数（Reward Shaping）、示范与离线学习（Imitation & Offline RL）**四个维度给出了标准的数学解决方案：

### 6.1 解决“16小时微观视野”：多尺度跨频状态表征与三频前瞻预测漏斗 (ADR 0054)

#### 1. 坚决否决方案：上下文条件强化学习 (Contextual RL / Latent Conditioning) —— 【正式否决】
- **理论构想**：将高层 VAE 潜在向量 $z_t \in \mathbb{R}^k$ 注入低层 Q-Net 或采用 FiLM 机制进行动态增益调制。
- **否决根因（ADR 0037 / ADR 0041 / ADR 0054）**：
  1. **严重破坏三流特征解耦红线**：微观低层策略将直接被高层宏观体制聚类与重构估计误差污染，丧失执行独立性；
  2. **诱发剧烈跨域 OOD 漂移**：高层 VAE 在体制交界处的潜变量扰动会直接瘫痪低层 Q-Net 的动作价值输出；
  3. **架构共识**：**坚决不做上下文条件强化学习**，低层策略网络完全依靠原生状态空间解决多尺度感知。

#### 2. 正式采纳方案：多尺度跨频状态表征与三频前瞻预测漏斗 (ADR 0054) —— 【正式采纳】
- **RL 理论方案**：
  在状态空间中显式引入分层时间跨度因果无量纲因子，将状态观测扩展为微观、中观与宏观扁平组合：
  $$s_t = [s_t^{\text{micro}}, s_t^{\text{meso}}, s_t^{\text{macro}}]$$
- **FineFT 原生闭环实现机制（ADR 0054）**：
  1. **扁平架构与网络零侵入**：维持 `Qnet` 极简单路结构，总维度 $N_{\text{states}} = 135 \sim 160$ 维，由 `fc1` 学习跨尺度非线性交互；
  2. **连续因果宏观算子 ($W \in \{720, 1440\}$)**：引入标度不变的均线偏离度（$\text{EMA Deviation}_{720}$）、区间动量（$\text{ROC}_{720}$）、趋势信噪比（$\text{Trend\_to\_Noise}_{720}$）、标准化斜率（$\text{Beta}_{720}$）与跨月基差滚动 Z-Score；
  3. **零 NaN 扩展窗口冷启动**：采用 `min_periods=48` 渐进因果动态扩展窗口，兼顾 `validate_no_nan` 约束与合约头部 20% 样本的完整保全；
  4. **三尺度分层前瞻漏斗**：
     - 微观流（$k \in [1, 12]$，门槛：`min_abs_ic=0.010, sc=0.55, ir=0.18`）；
     - 中观流（$k \in [16, 96]$，门槛：`min_abs_ic=0.015, sc=0.58, ir=0.15`）；
     - 宏观流（$k \in [192, 720]$，门槛：`min_abs_ic=0.020, sc=0.60, ir=0.12`）；
  5. **尺度分层聚类配额制**：微观 85~100 维、中观 35~45 维、宏观 10~15 维，杜绝宏观趋势指标被全局 0.80 聚类过度压缩为单一标量。
- **数学效果**：智能体从状态端直接因果感知 20~40 交易日大趋势方向，在大牛市中面对日内 2~3 小时微观急跌时坚定保持多头持仓，彻底根除逆势做空摸顶。

### 6.2 解决“无记忆 MLP 架构”：增广马尔可夫状态 vs 循环/注意力机制

#### 方案 A：增广马尔可夫状态 (Augmented Markov State，高频量化首选，零延迟开销)
- **RL 理论方案**：
  根据马尔可夫决策过程（MDP）的扩展理论，如果一个非马尔可夫历史路径依赖问题可以通过引入确定性累加器（State Augmentation）转换为一阶马尔可夫链，前馈网络（MLP）就能在数学上实现最优策略映射！
- **FineFT 原生改造机制**：
  在 `base_env.py` 的 `trading_info` 中，增加两个关于**浮盈高水位（High Watermark）**的一阶标量：
  1. **持仓历史最高浮盈收益率**：
     $$R_{\max}(t) = \max_{\tau \in [t_{\text{entry}}, t]} \frac{\text{UnrealizedPnL}_{\tau}}{\text{Margin}_{\tau}}$$
  2. **高水位回吐深度 (Trailing Drawdown / Retracement)**：
     $$\text{Retracement}_t = \max\left(0, \frac{R_{\max}(t) - R_t}{R_{\max}(t) + \epsilon}\right)$$
  - **数学效果**：通过将整段历史轨迹的关键特征压缩为一阶标量注入输入端，前馈 MLP 即可感知“当前已从最高点回吐了 30% 利润”这一马尔可夫状态。网络在训练中可轻松学出：当 $\text{Retracement}_t > 0.25$ 时将 Flat 平仓动作的 Q 值置为最高。

#### 方案 B：循环强化学习或门控 Transformer (DRQN / GTrXL)
- **RL 理论方案**：
  - **DRQN (Deep Recurrent Q-Network, Hausknecht & Stone)**：将 MLP 隐层替换为 LSTM/GRU，维持跨步循环隐藏向量 $h_t = \text{RNN}(h_{t-1}, s_t)$；
  - **GTrXL (Gated Transformer-XL for RL, Parisotto et al.)**：通过因果自注意力与跨段记忆缓存（Memory Cache），在不破坏 MDP 学习稳定性的前提下解决数百步时序信用分配（Credit Assignment）。
- **工程权衡**：
  时序记忆模型理论上限高，但前向推理耗时增加 5~10 倍。在 10 分钟交易频率下，**方案 A（增广马尔可夫状态）**在算力效率、执行确定性与效果上均占优。

### 6.3 解决“无路径惩罚的标量回报”：高水位回撤塑形与风险敏感 RL

#### 1. 路径依赖型奖励塑形 (Path-Dependent Reward Shaping)
- **RL 理论方案**：
  打破单纯“单步价格增量即收益”的无惩罚假设，将**浮盈高水位回撤（Trailing Drawdown Penalty）**显式纳入单步奖励函数：
  $$r_t = \Delta \text{PnL}_t - \text{friction}_t - \lambda_{\text{turnover}} \cdot \text{Turnover}_t - \lambda_{\text{dd}} \cdot \Psi(\text{Retracement}_t)$$
  其中回撤惩罚激活函数采用二次型设计：
  $$\Psi(\text{Retracement}_t) = \max(0, \text{Retracement}_t - \theta_{\text{allow}})^2$$
- **FineFT 原生改造机制**：
  - 设定允许的合理波动裕度（例如 $\theta_{\text{allow}} = 15\%$）；
  - 一旦持仓从最高峰值回吐超过 15%，每多回吐 1%，惩罚项以平方级爆发；
  - **数学效果**：强化学习贝尔曼方程在反向更新时：
    $$Q(s, a) = r_t + \gamma \max_{a'} Q(s', a')$$
    持有多头继续坐电梯会带来剧烈的负向 $r_t$，导致多头 Q 值断崖式暴跌，而平仓动作可以立即截断该负惩罚，迫使智能体自主收敛出“在见顶回撤初期立即主动保盈平仓”的策略行为。

#### 2. 风险敏感型强化学习 (Risk-Sensitive RL / Utility Optimization)
- **RL 理论方案**：
  - **微分索提诺比率 (Differential Sortino Ratio, Moody 2001)**：将最大化累积期望回报改为最大化下行方差调整后收益，只对下行负偏离施加平方惩罚，彻底消除正向浮盈与回撤的对称无感；
  - **CVaR (Conditional Value-at-Risk) 约束策略优化**：在优化目标中加入尾部 5% 资产回撤约束，迫使 Agent 抑制利润大幅回吐。

### 6.4 解决“上帝视角 DP 示范偏差”：因果滤波 DP 与特权蒸馏 (Privileged Learning)

#### 1. 因果平滑滤波动态规划 (Causal Smoothed Dynamic Programming)
- **RL 理论方案**：
  消除 DP 专家表对逐 Tick 微观原始价格的反向全知，给 DP 专家戴上“物理因果滤波器”。
- **FineFT 原生改造机制**：
  - 在 `create_optimal_q_table_from_df` 求解贝尔曼反向递归前，将输入的逐步价格数组 $P_t$ 替换为**因果平滑价格（如基于 EMA 或因果 Hodrick-Prescott 滤波的价格趋势线）**；
  - 或对 DP 的前瞻视野施加**物理前瞻截断（Lookahead Truncation，仅允许前瞻 12 步，并施加 10 倍换手阻尼）**；
  - **数学效果**：滤波后的 DP 专家在大牛市中会死死咬住多头，不会因为夜盘 2 小时的微幅下挫就做出神仙摸顶做空的操作，从而向学生经验池输出高度纯净、顺应大势的示范轨迹。

#### 2. 特权学习与保守离线蒸馏 (Privileged Learning / Conservative Offline RL)
- **RL 理论方案**：
  采用类似机器人控制中的“Learning by Cheating”双阶段范式：
  - **Teacher（特权专家）**：在训练期允许拥有完整环境信息甚至局部前瞻；
  - **Student（实盘模型）**：只接收真实因果可测的当前状态；
  - **蒸馏约束 (KL / CQL Regularization)**：学生模型不直接硬克隆专家的离散动作，而是通过保守性约束（Conservative Q-Learning, CQL / IQL）对专家由于特权信息做出的极端激进动作进行置信度加权丢弃。
