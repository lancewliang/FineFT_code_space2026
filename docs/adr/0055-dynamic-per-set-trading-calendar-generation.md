# 基于数据特征动态生成分集交易日历

为了支撑下游多预测期限特征审计（Feature Audit）以及强化学习环境对有效交易时间（Active Trading Time）的精准计算，在 `operator_futures.dataset_split.dataset_split` 中增加动态交易日历清单（`calendar_manifest.json`）的生成能力。用户于 2026-10-14 设计访谈确认此决定。

在训练历史数据中，早期阶段期货品种仅有白盘交易（上午与下午），后期阶段引入了夜盘交易，且节假日前夕存在取消夜盘等特殊安排。为精准反映真实历史交易边界，日历生成采用“品种标准时段模板 + 数据存在性动态激活”机制：
1. 白盘固定交易时段（`m1: 09:00-10:15`、`m2: 10:30-11:30`、`aft: 13:30-15:00`）由 `COMMODITY_CONFIGS` 标准模板保底生成，起止时间严格对齐交易所官方秒级撮合时刻，避免 K 线降采样打标导致的边界收缩。
2. 夜盘（`night: 21:00-23:00`）通过扫描前置自然夜时间窗内真实数据时间戳的存在性动态激活。早期无夜盘数据或节假日前夕不激活夜盘小节。
3. 遵循期货交易所官方交易日语义，夜盘作为交易日的第一小节，下午盘收盘作为最后一个小节，保证 `CalendarAdapter` 准确识别 15:00:00 为日盘收盘时刻（`_td_to_close`）。
4. 交易日历按 `train`、`valid`、`test` 分区各自独立生成，分别存放在各子集目录下（如 `train/calendar_manifest.json`），并在 `dataset_split_manifest.json` 的对应 set 项中注册 `calendar_manifest_path`，严格遵循子集时间边界隔离与防未来信息泄露原则。
