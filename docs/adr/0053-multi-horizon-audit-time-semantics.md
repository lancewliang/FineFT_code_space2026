# 多预测期限特征审计采用交易时间与显式交易日偏移

为了让 10min 与 30min 特征审计具有相同的未来目标语义，独立审计模块的 1h / 2h / 4h 按品种交易日历累计 60 / 120 / 240 分钟有效交易时间，跳过休市并允许跨 Session、跨 TradingDay；Today、NextTD、Next5TD、Next15TD 从当前决策时刻累计至 D、D+1、D+5、D+15 日盘收盘。用户于 2026-10-13 首轮设计访谈确认此决定。

原特征选择器的固定行偏移收益保持原行为。新审计接受维护交易日历与精确目标时点的成本，以避免缺失 Bar、部分 Bar 和不同采样频率改变预测期限；Next5TD / Next15TD 不采用包含今天的第 5 / 第 15 天。该定义成为审计标签版本的一部分，后续修改必须更新版本，不能直接混合比较不同口径的历史报告。
