# 0053. 增广马尔可夫状态五维交易特征契约与高水位回撤闭环架构

为彻底解决前馈多层感知机（MLP）“无历史记忆”导致的局部部分可观测马尔可夫决策过程（POMDP）病态缺陷，打破策略网络无法区分“主升浪初起”与“见顶大回撤”的认知分裂，我们决定将低层强化学习交易特征 `trading_info` 正式升级为五维显式契约，通过在状态端注入物理量纲统一的标的高水位浮盈率与即时回吐深度标量，与 ADR 0052 回撤流血奖励机制形成数学闭环，并坚决恪守与高层 VAE 的三流特征解耦红线。

## Status

accepted

## Context

在对前馈网络（MLP）在长周期趋势持仓过程中的数学表征与学习动态审查中，确认了以下深层矛盾：
1. **无记忆前馈策略在 POMDP 下的信用分配崩溃**：
   前馈策略网络 $\pi(a|s)$ 仅能依据当前观测向量 $s$ 进行映射。在同一标的收益率（如 $+10\%$）下，主升浪初期的正常持仓与自 $+50\%$ 暴跌回撤至 $+10\%$ 的大回吐在网络输入端表现为完全一致的特征；若仅引入 ADR 0052 的回撤流血惩罚而状态端缺乏一阶路径累加器，贝尔曼反向传播会向同一个状态输入灌入剧烈冲突的梯度目标（既要求提升多头 Q 值，又要求惩罚多头持仓），导致网络学崩或恐慌早退；
2. **ADR 0052 四维原位复用的理论局限**：
   ADR 0052 为保持张量维度兼容，将 `trading_info[2]` 原位替换为即时回吐率 $\text{Retracement}_t$。虽然网络理论上可通过当前收益 $R_t$ 与回吐深度隐式反解 $R_{\max} = R_t / (1 - \text{Retracement})$，但在持仓冲顶回落至成本线（$R_t \to 0$）附近时存在除零与数值病态压缩；网络无法显式解耦“浮盈微薄时的盘口正常抖动”与“重大利润高位见顶的大幅回吐”；
3. **分层解耦架构的红线坚守**：
   尽管研究文档曾设想将高层 VAE 潜变量 $z_t$ 注入低层状态作为上下文，但 ADR 0037 与 ADR 0041 确立的“三流特征解耦架构”是 FineFT 防过拟合与防御 OOD 漂移的立足之本。微观执行策略若直接摄入宏观体制变量，将直接被宏观估计误差污染并丧失泛化能力。状态增广必须严格限定在微观交易过程特征内部；
4. **历史兼容包袱的根除需求**：
   按 CLAUDE.md“零兼容包袱”原则，既然端到端原生 RL 路线本身必须重新训练低层网络，就必须在输入端给足充分、纯粹、无量纲的一阶马尔可夫统计量，彻底根除跨文件的魔数与隐式推断。

## Considered Options

- **选项 1：维持四维原位复用（ADR 0052 现有方案）**：
  *缺陷*：输入端缺少显式 $R_{\max}$，策略网络在成本线附近无法稳定感知峰值浮盈规模，对不同浮盈体量下的回撤敏感度学习困难。
- **选项 2：跨层注入高层 VAE 潜变量 $z_t$ 或体制网格 ID**：
  *缺陷*：严重破坏 ADR 0037/0041/0051 确立的分层强解耦基石，微观执行 Agent 受到高层体制估计误差直接污染，诱发严重 OOD 漂移。
- **选项 3：五维显式增广马尔可夫状态 + 全链路物理量纲对齐（选中）**：
  1. **五维特征张量契约 (`TRADING_INFO_KEYS`)**：
     将 `TRADING_INFO_KEYS` 明确升级为包含 5 个独立无量纲字段：
     ```python
     TRADING_INFO_KEYS = (
         "position_exposure",            # 0: 归一化持仓暴露 [-1.0, 1.0]
         "single_holding_return_rate",   # 1: 当前持仓标的价格变动率 R_t
         "peak_return_rate",             # 2: 历史最高标的浮盈率 R_max
         "instant_profit_retracement",   # 3: 即时浮盈回吐深度 Retracement_t
         "current_holding_duration_norm",# 4: 归一化持仓时长 tau_t
     )
     ```
  2. **标的价格物理变动率量纲对齐**：
     - 彻底摒弃历史遗留的杠杆资金收益率，将 `single_holding_return_rate` ($R_t$) 与 `peak_return_rate` ($R_{\max}$) 的物理基准完全统一为**标的标记价格变动百分比**：
       $$R_t = \frac{P_t - P_{\text{entry}}}{P_{\text{entry}}} \times \text{sign}(\text{position})$$
       $$R_{\max} = \text{clip}\left(\max\left(0.0, \max_{\tau \le t} R_\tau\right), 0.0, 1.0\right)$$
     - 消除期货不同品种保证金率差异引起的非平稳尺度漂移，并以 $[0.0, 1.0]$ 硬截断保障数值进入 MLP 时的数值稳定性；
  3. **死区门槛与硬饱和即时回吐定义**：
     - 当未持仓或 $R_{\max} < \theta_{\text{profit\_min}} = 0.08$ 时，$\text{Retracement}_t$ 恒输出 `0.0`，过滤微观盘口随机白噪声；
     - 当突破 8% 浮盈门槛后，输出严格截断在 $[0.0, 1.0]$ 的回吐比例：
       $$\text{Retracement}_t = \text{clip}\left(\frac{R_{\max} - R_t}{\max(R_{\max}, 1\times 10^{-12})}, 0.0, 1.0\right)$$
     - 即使跌穿成本线（$R_t < 0$），回吐特征在 1.0 处饱和，浮亏程度全权由 $R_t$ 表达；
  4. **与 ADR 0052 回撤奖励塑形的理论因果闭环**：
     - 状态输入中的 $R_{\max}$、$\text{Retracement}_t$ 与环境内部奖励扣罚 `reward -= drawdown_penalty` 共享相同的底层计算变量；
     - 负向流血惩罚精准作用于高回撤状态的神经元通路，驱动 $Q(s, \text{Hold}) \ll Q(s, \text{Flat})$，使智能体自发收敛出保盈平仓；
     - 保持 ADR 0052 保盈平仓换手豁免机制 100% 独立有效；
  5. **全链路工程参数化与零兼容包袱**：
     - 在系统级消除所有针对 `trading_info` 形状的硬编码魔数 4，统一以 `TRADING_INFO_DIM = len(TRADING_INFO_KEYS) == 5` 与命名索引驱动；
     - 同步升级 `base_env.py`、`low_level.py`（`fc_trading = nn.Linear(5, hidden_nodes)`）、GPU 显存 Replay Buffer 预分配张量与相关诊断工具；
     - 废弃旧版 4 维低层权重，遵循 fail-fast 原则，重训低层模型。

## Consequences

- **POMDP 转为严格一阶 MDP**：前馈 MLP 策略网络首次具备完整的持仓路径与利润峰值感知能力，彻底消除主升浪与见顶回撤的策略认知冲突；
- **奖励塑形效能最大化释放**：ADR 0052 的回撤流血惩罚信号获得与之完全对齐的状态输入“坐标”，网络具备了学懂“何时主动平仓止盈”的前提条件；
- **量纲纯粹与数值稳定**：标的价格无量纲变动率与 $[0.0, 1.0]$ 有界截断消除了杠杆非平稳性与极端离群点冲击；
- **解耦边界固若金汤**：低层网络专注于微观持仓与订单流，严禁宏观 VAE 污染，系统架构层次分明；
- **低层模型需要全面重训**：旧版低层 checkpoint 无法直接加载，需以五维契约执行预训练与多样化探索（Diverse Training）重训。
