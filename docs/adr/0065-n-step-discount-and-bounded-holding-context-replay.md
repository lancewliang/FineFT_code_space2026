# 多步后续价值折扣与有界持仓经验保留

用户确认先修复学习计算和经验去重，再自行重训；随后确认Q3采用“精确区分当前持仓、同组最多4条不同后续、随机轮换、满池更新”。本次不改变模型结构、6步动作保持、手续费、换手惩罚或高层风控，不启动训练。

## 决定

1. 预训练与多样化训练均将多步目标写为 `R_n + (1-done) * gamma**n_step * next_Q`。当前可bootstrap样本均累计完整 `n_step` 步；短窗或终止样本沿用既有终止掩码，不引入新的截断解释。DP教师表仍为单步递推，无须改成 `gamma**n_step`。
2. 经验组精确使用模型实际消费的 float32 持仓上下文：`previous_action`、完整四维 `trading_info`、可用动作掩码及小时/分钟输入，结合行情身份和目标动作。不对收益、回撤或时长再分粗桶；正负零规范为同值，拒绝非有限身份字段。教师Q和收集时的误差不属于身份。
3. 紧凑路径用本次训练内不可变共享行情的 `(df_index, step_index)` 标识行情，避免逐条复制宽行情向量；完整转移路径按规范化行情内容标识。两者使用相同的持仓上下文精度和保留规则。每次正式重训使用新的实验目录/经验池，不把旧坐标索引复用于另一份行情数据。
4. 同组不同后续以累计回报、后续行情与模型可见上下文、终止标记区分。最多保存4条；完全相同的已驻留转移合并，旧误差指标只可刷新该完全相同转移的教师/诊断元数据，不比较不同结果的优劣。
5. 满4条时，使用独立、由seed初始化的随机数生成器，随机选择一个现有槽位替换为新结果。每个新候选都进入，因而偏向较新的探索结果；这是随机轮换，不宣称是对所有历史不同结果等概率的蓄水池抽样。不按利润、最大亏损或旧教师分歧评分选择路径，也不保证保住每条罕见尾部结果。
6. 保留各体制固定容量、全局容量上限与现有分格随机采样。新经验组满格时沿用FIFO；组内轮换和FIFO均同步回收旧记录键，空组立即删除。索引只随驻留记录增长，不维护所有历史结果的无界去重表。淘汰的旧结果再次出现可重新入选。
7. 每轮继续收集完整探索任务集，取消因满池或连续无新增而永久停止探索的分支；训练仍受配置轮数与现有评估早停控制。满池只约束保存量，不取消后续新策略的探索机会。

## 为什么没有直接采用优先经验回放

现有收集指标主要为教师Q与所选动作Q的差，并非修正后的多步Bellman误差。先保持分格随机采样，避免在学习计算修复的同一轮引入新的抽样分布与损失加权。完整PER需要真实残差刷新和抽样偏差处理，应独立研究。

## 兼容性与验证

- 回放导出标记 `replay_semantics_version=2` 和 `max_outcomes_per_decision=4`。现有diverse快照是训练张量导出，不新增历史索引恢复器；不承诺从旧快照恢复相同的随机替换序列。
- 旧模型参数形状兼容，但未获得正确多步目标下的重训资格；新旧训练结果需分目录保留。
- 检查两个真实update入口的1/18步目标、正负终点价值与终止掩码；检查持仓字段区分、不同后续共存、组上限、种子复现、FIFO索引回收、紧凑/完整批次以及满池和多轮无新增时仍继续探索。
- 单次测试中的合成优化器更新仅验证函数，不等同于策略重训。真实收益、交易摩擦和回撤改进均待用户重训后评估。

本ADR修订 [ADR-0052](0052-compact-spatio-temporal-trajectory-ipc-and-micro-batched-ingestion.md) 的去重等价关系，保留其紧凑回传和微批次目的，并保留 ADR-0012 的轨迹内多步累加及体制隔离。
