# Agent 策略分类采用互斥持仓回合模型

Agent 策略分析直接消费 `test_agent_index.py` 的逐步交易事实，以开仓至平仓、换向或数据结束的持仓回合作为唯一分类单位，不再使用固定窗口、K 线形态或旧策略形态。每次开仓和同向加仓依据此前五个 mark price 的动量产生方向票，并按新增仓位加权汇总为互斥的趋势追随或均值回归；这样分类描述 Agent 的入场行为，不会用交易结果倒推策略类型，也不会重复累计回合利润。

## Consequences

换向行的 step reward 全部归入被结束的旧回合，新回合从后续行累计利润。无法取得五个先行价格、加权得分为零或只有不可观察初始开仓的回合保持未分类，不进入两类正式汇总。

Agent 选择必须读取 `label_semantics.json`：上涨 Label 以正的做多回合平均利润排名，下降 Label 以正的做空回合平均利润排名，震荡 Label 以整体回合平均利润排名。总利润和最大利润仅作诊断，不作为最佳 Agent 的首要排序指标。
