# 0044. 基于全 GPU 显存直存经验池、单 Context 精准推断与异步后台评测的高性能训练架构

为彻底解决低层加权优势强化学习训练（`parallel_weight_advantage_pretrain.py`、`parallel_diverse_train.py`）中单 Epoch 耗时长达 9.2 分钟、96 进程引发 4.67GB Swap 磁盘颠簸、探索推断冗余 13 倍算力以及训练期 48GB PCIe 同步拷贝阻塞问题，我们决定实施基于全 GPU 显存直存经验池、单 Context 精准推断、异步后台评测与进程池理性缩编的系统重构。

## Status

accepted

## Context

在目前的商品期货 10min 低层强化学习训练（`FineFT/script/train/train_commodity_fu_10.sh`）中，系统暴露了四大致命性能瓶颈：
1. **进程数过载导致 4.67GB Swap 颠簸**：配置 `--diverse_num_workers 96` 导致 96 个 Python+PyTorch 进程基底物理内存消耗达 50.8GB，击穿宿主机 62GB 物理内存上限，触发 4.67GB 磁盘 Swap 换页与严重的 Major Page Fault I/O 顿卡；
2. **探索决策算力浪费 92.3%**：`_act` 每次调用 `model(...)` 均遍历计算 `ensemble_Qnet` 中的全部 13 个子网络并丢弃其余 12 个，单轮产生 2156 万次无用前向传播；
3. **经验池碎片化与 PCIe 同步阻塞**：经验池维护 80 万个 Python 元组与散装字典，每轮在 Python 循环中用 `np.stack` 重复动态堆叠，且 600 次训练迭代由 CPU 串行切片并同步向 GPU 拷贝 48GB 数据；
4. **评测阶段串行阻塞 165 秒**：每 2 轮在主进程单线程中串行回测 15 个 Episode，每步单样本 GPU 推断并触发 `.item()` 同步，占单轮总耗时的 30%，期间全部 Worker 空转。

## Considered Options

- **选项 1：维持现状，仅调大宿主机物理内存**：无法解决 13 倍子网推断冗余、48GB PCIe 拷贝阻塞与单线程串行评测瓶颈。
- **选项 2：全异步流式 Actor-Learner 双缓冲架构**：理论吞吐最高，但打破了 FineFT 现有的 6 阶段方向性体制课程（Curriculum Phase）严格轮次边界，引入了 Off-policy 策略滞后与梯度陈旧性风险，重构侵入度极高。
- **选项 3：全 GPU 显存直存经验池 + 单 Context 精准推断 + 异步后台评测 + 进程池缩编至 40 个 Worker（选中）**：
  1. **探索剪枝**：`_act` 精准调用 `model.qnet_list[context_index]`，推断算力立减 92.3%，探索耗时从 143s 降至 35s；
  2. **进程池治理**：Worker 缩编至 36~40 个，物理内存稳态降至 28GB，**Swap 使用量彻底清零（0 MB Swap）**，消除所有磁盘顿卡与调度争用；
  3. **显存直存经验池**：利用 GPU 剩余的 8.2GB 空闲显存，将 80 万条经验（紧凑数值张量仅 1.01GB）直接常驻 GPU 显存，600 次训练迭代在 GPU 内执行纳秒级切片采样，**PCIe 拷贝量彻底清零**，训练耗时从 241s 降至 50s；
  4. **异步后台评测**：训练完成后对模型权重进行浅拷贝快照（<2ms），投递至后台线程/进程异步执行，主训练循环零等待立即推进至下一轮，**评测关键路径耗时从 165s 彻底降为 0**；
  5. 保持严格的同步 Epoch 课程学习边界不变，算法数学语义与收敛轨迹 100% 等价。

## Consequences

- **正面收益**：
  - 单轮 Epoch 总耗时从 **~550 秒 (~9.2 分钟)** 骤降至 **~85 秒 (~1.4 分钟)**，整体提速 **5~6 倍**；
  - 全量 75 轮训练总耗时从 **~11.5 小时** 压缩至 **~1.8 小时**；
  - 宿主机物理内存占用降低 50%（稳态 28GB），**彻底杜绝 4.67GB 磁盘 Swap 颠簸**；
  - 彻底清零 600 次梯度更新中累计 48GB 的 PCIe 传输，训练期 GPU 算力利用率由 66% 拉满至 95%+；
  - 算法收敛性、课程学习进度与最终模型参数等价。
- **权衡与约束**：
  - GPU 显存占用稳态上升约 1.01GB（从 7.7GB 升至 ~8.7GB），需确保训练批量与显存配额处于 16GB 安全线以内；
  - 评测指标在 TensorBoard 中呈现轻微的异步延迟（半轮至一轮），若触发早停判定需通过线程安全原子标志位通知主循环。
