# 0050. 非对称方向性调仓惩罚与动态规划自洽奖励塑形架构

为了彻底解决对称换手惩罚在单边强趋势中因“开仓高摩擦”引发的“不作为陷阱（Zero-Action Trap）”，以及在横盘震荡中因“摩擦过低”诱发微观噪声频繁“刮头皮（Scalping）”的结构性矛盾，我们决定确立**非对称方向性调仓惩罚（Asymmetric Directional Turnover Penalty）**机制：依据宏观体制（`regime_grid_id`）将调仓行为划分为“顺势/避险”与“逆势/噪声乱动”，分别施加基准费率（`turnover_base_rate`，默认 0.0001）与逆势阻尼费率（`turnover_adverse_ratio * turnover_base_rate`，默认 0.0006），并实现环境步进（`Base_Env.step`）与离线动态规划（`create_optimal_q_table_from_df`）的全链路数学闭环自洽。

## Status

accepted

## Context

在 ADR 0049 确立对称名义货值换手惩罚（默认 0.0002）后，我们进一步针对多体制分层训练（`RegimeStratifiedReplayBuffer`）进行了压力测试与理论质询：
1. **单边趋势与开仓摩擦的天然冲突**：在大幅上涨或单边大跌中，策略的核心诉求是“迅速建仓并咬住波段，死拿持仓防洗盘”。若直接大幅调高全局换手惩罚（如 0.005），Agent 空仓建仓（$0 \to +1$）的第一步即承受巨额名义货值负惩罚，在短视或探索期极易收敛至“永远空仓”的不作为不动点；
2. **震荡市信噪比与止损避险的天然冲突**：在横盘震荡体制中，单边波段极窄且充满高频随机噪声。若换手惩罚过低，Agent 将在微观假突破中频繁来回倒手，被手续费和滑点双向收割；但若在震荡中施加对称高惩罚，被套持仓又将因畏惧调仓成本而不敢及时平仓止损；
3. **经验池分层与教师示范一致性**：强化学习低层预训练依赖动态规划（DP）专家表（`create_optimal_q_table_from_df`）生成示范轨迹。若在线环境执行非对称惩罚，而 DP 专家表仍沿用对称惩罚，离线示范动作将与在线最优策略产生系统性漂移。

## Considered Options

- **选项 1：按体制网格静态配置 9 格惩罚大字典**：
  为九宫格每个 `regime_grid_id` 单独设定一个静态惩罚率。
  *缺陷*：仍然属于对称惩罚，单边体制下开仓与平仓惩罚相同，无法消除“顺势建仓受阻”的问题，且超参数膨胀至 9 个，极易对特定历史数据产生过拟合。
- **选项 2：非对称方向性调仓惩罚 + 全链路自洽（选中）**：
  1. **参数化架构（Q2 选项 B）**：
     - `turnover_base_rate`（默认 `0.0001`，1 bps，对标国内期货真实佣金）；
     - `turnover_adverse_ratio`（默认 `6.0`，即逆势阻尼惩罚为 `0.0006`，6 bps）；
     - 派生 `turnover_adverse_rate = turnover_base_rate * turnover_adverse_ratio`；
     - 向后兼容：保留 `--turnover_penalty_rate`，未指定 `adverse_ratio` 时自动退化为对称模式。
  2. **三态方向性状态机（Q1 选项 A）**：
     - 利用行级物理特征提取 `slope_bin = regime_grid_id % 3`（`2`: 上涨, `1`: 震荡, `0`: 下跌）；
     - 上涨体制（`slope_bin == 2`）：顺势多头操作（`new_pos > old_pos`）执行 `base_rate`；逆势离场/做空（`new_pos < old_pos`）执行 `adverse_rate`；
     - 下跌体制（`slope_bin == 0`）：顺势空头操作（`new_pos < old_pos`）执行 `base_rate`；逆势离场/做多（`new_pos > old_pos`）执行 `adverse_rate`；
     - 横盘震荡（`slope_bin == 1`）：新增风险敞口（$0 \to \pm 1$）或直接反手（$+1 \leftrightarrow -1$）执行 `adverse_rate`，大幅抑制微观杂波试盘；平仓离场（$\pm 1 \to 0$）执行 `base_rate`，鼓励快速止损归零防守。
  3. **整步定性原子计费（Q3 选项 A）**：
     - 跨零点直接反手（$|\Delta \text{pos}| = 2$）作为一个动作原子，直接由终态相对于宏观体制的方向属性一次性确定单步费率，保证 $O(1)$ 计算复杂度并与 DP 贝尔曼反向递归无缝契合。
  4. **DP 专家 Q 表全链路镜像与优雅降级（Q4 选项 A）**：
     - 在 `futures_util.py:1516` 的 `create_optimal_q_table_from_df` 贝尔曼更新中，读取当前时间步的 `regime_grid_id` 并完全镜像应用上述非对称状态机；
     - 若输入数据缺失 `regime_grid_id`，自动优雅降级为对称的 `turnover_base_rate`，保证轻量测试与无体制环境的绝对稳健性。

## Consequences

- **正面收益**：
  - **顺势建仓零阻滞**：大涨大跌行情中进场调仓仅扣减万分之 1 的基准手续费，Agent 毫无开仓顾虑；
  - **锁定波段持仓惯性**：一旦处于趋势持仓中，任何早退平仓或逆势摸顶动作均面临 6 倍高额阻尼惩罚，强力锁死持仓周期；
  - **净化震荡市交易**：震荡中试盘成本高昂，迫使策略自动收敛至空仓观望，避免日内频繁“刮头皮”造成的摩擦失血；
  - **理论闭环严密**：离线 DP 专家示范与在线强化学习奖励完全对齐，从源头消除了行为漂移。
