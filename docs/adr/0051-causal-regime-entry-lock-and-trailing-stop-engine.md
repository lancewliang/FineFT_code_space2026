# 0051. 因果体制单向开仓硬锁与移动追踪止盈确定性风控架构

为根治离线动态规划（DP）专家表由于“全知未来价格的上帝视角（Oracle Bias）”在局部微观杂波中生成的“神仙逆势摸顶/抄底”误导低层 Agent，以及在波峰“零回撤神仙平仓”导致模型缺乏回撤止盈示范而引发的利润大幅回吐缺陷（如 `fu2503` 逆势做空亏损 126 点、`fu2505` 浮盈回吐 51.4%），我们决定确立一套全链路自洽的解法体系：在离线 DP 求解与在线高层路由推断中同步确立**因果体制单向开仓硬锁（Directional Entry Lock）**，并在高层执行层确立 **Tier 4 移动追踪止盈引擎（Trailing Profit Stop Engine）** 与 **时空双重防再入护栏（Dual Spatiotemporal Re-entry Guard）**。

## Status

accepted

## Context

在 2026-10-08 燃料油 10 分钟验证集长周期（2,800 步以上）主力合约的实证回测与深度理论审查中：
1. **DP 专家的上帝视角套利误导**：离线 DP 算法通过全时序反向逆序递推（Backward Induction）求解，拥有完全预知未来的上帝视角。在大牛市中，只要夜盘回调 30 点，DP 必然在最高点做空并在谷底平仓翻多。这给仅有 16 小时局部特征视界的低层 Agent 输送了严重错误的示范，导致实盘中 `fu2503`（单边暴涨 +36.7%）频繁尝试做空（692 步），净亏损 -126 点；
2. **零回撤巅峰出场导致经验池示范真空**：DP 在波峰以 0% 回撤完美离场，导致整个经验池中完全不存在“见顶回撤 15%~20% 后平仓止盈”的行为轨迹；实盘模型面对见顶下跌不知所措，在 `fu2505` 中眼睁睁看着浮盈从最高 +697.56 元回吐 51.4% 至 +339.17 元；
3. **多样化探索覆盖的客观规律**：Stage I 训练包含 4 个 Epoch 的多样化探索（Diverse Training），持续生成数十万步样本并频繁采样更新。若仅在预训练 Warmup 阶段注入合成回撤轨迹，必然会被后续海量的多样化样本稀释和覆盖；必须在高层执行层构筑确定性物理护栏。

## Considered Options

- **选项 1：价格输入层因果平滑滤波（Causal Price Smoothing）**：
  在求解 DP 前对价格序列施加低通滤波。
  *缺陷*：平滑后的虚拟价格与真实的五档盘口（`ask/bid`）产生物理脱节，导致模拟撮合与深度滑点严重失真。
- **选项 2：打破分层解耦，将体制特征直接送入低层 Q-Net**：
  让低层网络直接学习体制条件分支。
  *缺陷*：严重破坏 ADR 0037/0041 确立的防过拟合基石，使微观 Agent 受到高层体制估计误差的直接污染并诱发 OOD 漂移。
- **选项 3：仅在预训练 Rollout 阶段注入合成止盈轨迹**：
  *缺陷*：在 Stage I 训练中，多样化探索（Diverse Training）的 Replay Buffer 采样与 TD 更新会迅速稀释并覆盖预训练阶段学到的行为模式。
- **选项 4：全链路因果体制硬锁 + 执行层 Tier 4 移动追踪止盈双轨护栏（选中）**：
  1. **DP 求解端宏观体制硬掩码（futures_util.py）**：
     - 在贝尔曼反向递归中读取 `regime_grid_ids_array` 并解析 `slope_bin = regime_grid_id % 3`；
     - 上涨体制（`slope_bin == 2`）：严禁逆势开空/翻空（禁止 $0 	o -1$ 与 $+1 	o -1$，转移值赋为 `-max_punishment`），但允许持有多头时平仓归零避险（$+1 	o 0$）；
     - 下跌体制（`slope_bin == 0`）：严禁逆势开多/翻多（禁止 $0 	o +1$ 与 $-1 	o +1$，转移值赋为 `-max_punishment`），但允许持有空头时平仓归零避险（$-1 	o 0$）；
     - 震荡体制（`slope_bin == 1`）：保持双向开放，由 ADR 0050 非对称调仓惩罚约束。
  2. **高层路由执行端动作掩码镜像（vae_routing_util.py）**：
     - 在前向推断时，读取高层 VAE 预测体制，对 `avaliable_action` 执行完全镜像的单向开仓硬锁，若低层策略输出逆势动作则物理拦截并标记 `ActionDecisionReasons.TREND_ENTRY_LOCK`。
  3. **Tier 4 移动追踪止盈引擎（vae_routing_util.py）**：
     - 激活门槛：单笔持仓标的价格相对浮盈率达到 `--trailing_stop_activation_threshold 0.08`（+8%）；
     - 回撤触发：自历史最高浮盈 $R_{\text{max}}$ 回撤达到 `--trailing_stop_retracement_ratio 0.25`（25%）时，强制规则平仓至 Flat 并标记 `ActionDecisionReasons.TRAILING_PROFIT_STOP`；
     - 保底约束：触发离场点不得低于开仓成本 + 0.3%，确保锁死正收益。
  4. **时空双重防再入护栏（Dual Spatiotemporal Guard）**：
     - 触发移动止盈后，激活 `--trailing_stop_cooldown_steps 24`（4 小时单向冷静期）；
     - 冷静期归零后，仍要求当前标记价格突破此前峰值标记价格（$P_t \ge P_{\text{peak}}$，前高破位再入）或高层宏观体制发生转移后，方允许再次同向进场，彻底杜绝阴跌接飞刀；拦截时标记 `ActionDecisionReasons.TRAILING_STOP_COOLDOWN`。
  5. **标准化审计归因三件套集成**：
     - 扩展 `ActionDecisionReasons` 枚举，并在回测诊断报告与风险 CSV 中统计硬锁与止盈事件。

## Consequences

- **正面收益**：
  - **彻底杜绝单边大势中的神仙逆势摸顶**：DP 专家 Q 表与在线高层执行层双重锁定，从源头消灭 `fu2503` 等合约的逆势亏损；
  - **确定性锁定大过山车行情浮盈**：`fu2505` 回吐 51.4% 的历史重演被物理终止，回撤止盈在回吐 25% 处果断截断，直接保全绝大部分利润；
  - **时空双重防再入彻底消灭阴跌送人头**：前高未破之前绝不再次追入，杜绝冲动追回；
  - **零重训即刻生效**：执行层 Tier 4 引擎对现有 checkpoint 直接起效，立竿见影助推长周期主力合约跨越 15% 目标。
