# 多预测期限审计独立于原特征选择且不反馈修改

为发现原短期限统计门禁遗漏的预测关联，新增审计独立读取 Stage 6 全部因果可用且满足基础质量要求的候选，原三流门禁、流专属黑名单与入选结果仅作对照注释；审计结果不回写选择列表、阈值、训练输入或模型。用户于 2026-10-13 两轮访谈确认此边界，代价是独立维护标签及统计口径，收益是可以评价原门禁未保留的长期关联，同时保持原训练流程行为不变。

10min 与 30min 分别使用其原生特征和回看窗口，期限收益保持同一真实合约，不拼接换月价格。该方案选择审计既有特征的真实用途，而非新增等物理回看窗口的特征重建实验；跨频率结论必须披露历史跨度差异，并使用共同有效样本辅助比较。
