## 目标项目中的事实与适配

当前项目使用 volatility 与 slope 两轴，按 Slot ID = volatility_index × num_labels + slope_index 对应 Selection Manifest。分位数可来自 Routing Quantile Cache，或来自相同评分协议的实时 VAE 推断。

现有 absolute 门控按是否持仓选择宽松门槛，并每步按两个轴的最高分重选 Slot；它没有跨步的当前专家身份与候选确认。现有 hierarchical 门控要求领先第二名，不能直接作为新策略恢复的前置过滤。现有普通动作持续期还可能跳过专家推断，与 Q1 的含义不同。

因此新增显式选择的 expert_hysteresis 策略，保留历史策略用于基线重放。不是给 legacy 策略简单增加一个 while 或 sleep，也不以持仓状态代替路由状态。

本目标项目规则接管使用现有防御动作，empty_model 使用 ADR-0061 的有限持仓缓冲与 No New Risk；旧单轴示例中的“持仓回撤低于 5% 时重复旧动作”不作为本项目的新契约。

## 分数与参数

- V[v]：波动率轴 v 的原始平滑分位数。
- S[s]：斜率轴 s 的原始平滑分位数。
- A = (v_A, s_A)：当前有效 Slot；B = (v_B, s_B)：本步最高分候选 Slot。
- H_v、H_s：各轴保持门槛；E_v、E_s：各轴进入门槛，分别满足 0 <= H < E <= 1。
- Δ：发生改变的轴相对当前 Slot 所需的共享最低领先幅度，非负且仍须严格领先。
- K：三类接管共用的正整数确认步数。

不将两个轴的分数相乘或相加后称为盈利概率。两轴 H/E 可用已有退出比率表示，即 H_axis = exit_ratio × E_axis；正式配置要求 0 < exit_ratio < 1。比率为 1 或 K 为 1 只适合明确标注的弱化对照，不静默作为完整迟滞配置。

## 每步处理顺序

1. 原有硬止损、断路器等抢占仍先执行；风险阻断的步骤不累计普通候选确认，不跨阻断拼接连续证据。
2. 对输入普通路由的两个分数向量检查非空、维度稳定、数值有限且位于 [0, 1]；检查 Slot 身份及 Manifest 匹配。
3. A 任一对应轴低于 H，当步撤销资格；普通失效本身不清除此前合格的候选证据。
4. 构造两轴最高分集合的笛卡尔积。有效 A 在集合中则保持 A；否则优先仍在集合中的已有候选，最后按稳定 Slot 顺序选择 B。
5. 若选中的主导 Slot 为 empty_model，使用目标项目原有 No New Risk 分支；不能将空槽包装成正常专家，或通过回填次优模型绕过空槽约束。
6. A 仍有效时，B 的两个轴都须达到各自 E；每个改变的轴都须相对 A 严格领先且差值至少为 Δ。不变的轴不要求领先自身。
7. A 不存在时，B 的两个轴达到 E 即可确认，不要求相对第二名的领先幅度。
8. 同一 B 本步继续合格，计数加一；更换为另一合格候选，从 1 开始；不合格清零。
9. 本步达到 K 就由 B 原子接管并清除待确认候选。未达到 K 时，有 A 就由 A 重新推断动作，无 A 就规则接管。
10. 实际动作仍经过原有可用动作、冷静期与 No New Risk 等约束。路由保持不代表实际成交、保持原仓位或冻结旧动作。

候选是整个 Slot，两轴不能各自使用独立计数拼接一个未经连续确认的专家。独立合约与独立回测有各自状态，不能共享计数；进入正式决策前沿用现有评分预热。

## 边界与场景

| 输入或事件 | 预期外部行为 |
| --- | --- |
| A 的两轴恰好等于 H | A 仍有效 |
| B 两轴恰好等于 E，其他条件满足 | 本步可计入确认 |
| 改变轴的正差值恰好等于 Δ | 本步可计入确认 |
| Δ = 0，A 与 B 同分 | 不能进行同分替换 |
| A 有效，B 仅单步领先 | 保持 A，A 每步重新给动作 |
| B 连续合格 K 步 | 第 K 步整个 Slot 切换 |
| A 失效，B 未达 E 或未完成 K | 规则接管，不延长 A 的使用 |
| B 已合格 K-1 步，本步仍合格且 A 失效 | 本步 B 直接接管 |
| B 与 C 并列最高，B 是已有候选 | 保留 B 的连续证据 |
| B 不达标或被严格更高的 C 取代 | 不复用 B 的计数 |
| 无有效专家、两个候选相近或并列 | 不额外设置第二名差距门槛 |
| 主导 Slot 为 empty_model | 禁止新增风险；持仓有限缓冲退出，不调用过期普通专家 |
| 硬止损或断路器抢占 | 当步按原风控处置，不等待 K |
| 无效分数或 Manifest 变化 | 明确报错，停止本次回测 |
| 下一个独立合约或独立运行 | 路由状态与计数重置 |

## 参数校准与验收

冻结两轴 VAE、参考分布、窗口与 gamma。使用未用于这些模型训练及专家挑选的时间验证段，校准两轴进入门槛、退出比率、Δ 和 K，并保存对应 H/E。最终测试不反向参与选参；已有旧阈值只能作为候选起点，因为当前专家判定与旧 max 判定并不等价。

主测试接缝是现有公开 get_action：输入固定双轴分数序列、可变化的假专家输出和可控账户状态，检查最终动作、选中 Slot 与审计归因。真实策略输出变化时，保持相同专家也必须出现最新动作，不能仅靠最终专家 ID 证明 Q1。

补充调参入口及最终回放的参数一致性、预计算缓存与同协议评分的一致性、跨合约重置和风险抢占回归。测试断言外部行为，不将内部容器布局或私有函数调用顺序当作契约。

回测同时报告 Slot 切换、短期切回、确认等待时间、规则占比、实际换手与费用、净收益和最大回撤；专家切换本身不能再计一次手续费。延迟同时报告决策步数和实际时长。数值参数及风险容忍上限尚未通过校准确定，因此不宣称绩效改善。
