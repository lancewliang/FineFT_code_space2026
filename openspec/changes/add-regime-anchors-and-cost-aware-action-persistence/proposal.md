# Spec: add-regime-anchors-and-cost-aware-action-persistence

## Why

`fu/30min` Low-level Agent 在低波动强方向行情中缺少可泛化的状态表示，并会在小 Q 值差下产生无效换仓；现有训练/验证分布表明目标行情并非整体样本稀缺，因此应优先改进表示、条件评估和动作保持。

## What Changes

- 增加七个因果、尺度无关的市场状态锚点 State Feature。
- 为 Feature Selection 增加 train-only 4×4 条件指标和受限的锚点条件保留规则。
- 为训练贪心分支和全部 Low-level 推理消费者增加共享的成本感知动作迟滞。

## Impact

- 扩展 `commodity-futures-feature-engineering` capability。
- 新增 `fineft-cost-aware-action-persistence` capability。
- 新能力默认关闭，现有数据和模型产物保持兼容；`fu/30min` 通过隔离消融决定是否启用。

## Problem Statement

当前 `fu/30min` Low-level Agent 在“方向明确但波动很低”的行情中缺少稳定适应能力，表现为上涨或下跌过程中的频繁换仓、方向保持不足，以及二维 Agent 选择结果在低波动强方向格中没有可接受模型。

现有数据诊断不支持“目标行情样本普遍不足”这一主因假设：按每个合约内因果滚动 48 Bar 计算并使用 train-only 四分位阈值后，训练集共有 15,339 个可用步骤，低波动两档与强负/强正斜率四格合计占 19.4%；验证集对应占比为 18.1%，train/valid 二维分布 PSI 为 0.0761。问题更可能来自表示能力、Feature Selection 的全局平均指标，以及低波动时过小 Q 值差导致的动作抖动。

当前 150 个 State Feature 中存在短周期趋势、ADX、波动率和若干标准化收益代理，但没有显式的长窗口有符号 Log 价格斜率、趋势/噪声比、方向效率、趋势拟合优度组合。若干代理特征在 valid 上出现明显 IC 衰减或符号翻转，因此不能只依靠全局 IC/RankIC 判断其在特定市场状态中的价值。

本变更只实施此前方案中的优先级 1、2、4：增加因果市场状态锚点 State Feature、让 Feature Selection 评估全部 16 个斜率×波动率组合、增加成本感知的持仓切换迟滞。

## Solution

增加一组最小、因果、无绝对价格的市场状态锚点 State Feature，直接描述中长窗口方向、趋势纯度和相对波动状态。Feature Selection 使用 train-only 统一阈值把每个合约的可用步骤映射到 4×4 统计格，对全部 candidate State Feature 输出逐合约及聚合的条件 IC/RankIC，并允许满足跨合约稳定性门槛的锚点通过条件保留规则进入最终 State Feature。

Low-level Q 策略增加共享的成本感知动作选择规则。模型先提出可用动作中 Q 值最大的候选动作；只有候选动作相对当前动作的 Q 优势严格大于该次换仓的预计执行成本与非负安全边际之和时才换仓，否则保持当前动作。该规则应用于训练的贪心分支和所有 Low-level 推理消费者，探索动作和 DP expert path 不受限制。

新能力默认关闭以保持旧实验可复现。`fu/30min` 通过固定数据、固定种子和相同训练预算执行基线、锚点/条件选择、锚点/条件选择+成本迟滞三组消融；只有验证集发布门槛通过后，才把增强配置作为该数据集的新默认实验配置。

## User Stories

1. **作为 Feature Engineer，我希望 Agent 能直接观察低噪声趋势。**
   - 当输入价格持续平滑上涨时，有符号斜率、趋势/噪声比和方向效率应为正，趋势拟合优度应接近 1。
   - 当输入价格持续平滑下跌时，前三个方向相关量应为负或保留负方向，趋势拟合优度仍应接近 1。
   - 当价格完全不变时，所有方向量和拟合优度应返回有限的中性值，不产生 NaN 或 Inf。

2. **作为数据管道维护者，我希望新增 State Feature 不包含未来信息。**
   - 任一时点的输出只能使用该合约截至当前 Bar 的数据。
   - 给输入追加未来 Bar 后，既有前缀的特征值不得变化。
   - 滚动状态在合约边界重置；不跨合约拼接窗口。

3. **作为跨品种研究者，我希望新增 State Feature 不依赖绝对价格单位。**
   - 将同一价格序列整体乘以正常数后，所有新增特征应在数值容差内保持不变。
   - 非正价格应 Fail-fast，不得静默替换为零或绝对值。

4. **作为 Feature Selection 使用者，我希望看到训练数据全部 16 个二维组合的步骤状况。**
   - 每个斜率格 0–3 与波动率格 0–3 的组合都必须出现在统计产物中，包括零样本格。
   - 每格必须记录步骤数、占比、参与合约数和可评估特征数。
   - 16 格步骤数之和必须等于排除滚动 warm-up 后的可用步骤数。

5. **作为模型研究者，我希望验证集沿用训练集定标，避免数据泄漏。**
   - 斜率和波动率阈值只允许从全部训练合约的可用步骤拟合。
   - valid 只应用已持久化的训练阈值并生成 report-only 条件指标。
   - test 不参与阈值拟合、Feature Selection 或配置选择。

6. **作为 Feature Selection 使用者，我希望识别全局平均较弱但在目标市场状态稳定有效的锚点。**
   - 全部 candidate State Feature 均输出 16 格条件 IC 和 RankIC。
   - 只有声明为市场状态锚点的候选特征可以通过条件规则被补充保留，普通候选仍遵循现有全局筛选规则。
   - 条件保留必须同时满足最小样本、最小合约覆盖、跨合约符号一致性和条件 RankIC 下置信界门槛。

7. **作为审计者，我希望能复现二维状态划分和条件选择。**
   - Feature Selection Manifest 必须记录定标集合、窗口、斜率和波动率公式、四分位阈值、warm-up 行数、16 格计数、条件门槛和被条件规则补充保留的特征。
   - 相同有序输入与配置必须产生相同阈值、格编号、指标和最终特征顺序。

8. **作为 Low-level Agent，我希望在 Q 优势不足以覆盖交易摩擦时继续持仓。**
   - 若最佳候选就是当前动作，则直接保持。
   - 若最佳候选不同，但 Q 优势小于或等于预计换仓成本加安全边际，则保持当前动作。
   - 只有 Q 优势严格大于门槛时才采用候选动作。

9. **作为交易执行维护者，我希望预计成本与真实环境语义一致。**
   - 每个可用动作的预计成本使用当前可见盘口、仓位、杠杆、手续费率和 Reverse Position 语义进行无副作用估算。
   - 同动作成本为零；不可用动作成本不可参与候选比较。
   - 预计成本使用与 Q 值相同的钱包余额单位，并由非负手续费与不利滑点组成。

10. **作为训练维护者，我希望训练和推理使用同一动作规则。**
    - diverse training 的贪心动作、Low-level 独立测试和 High-level 路由后的 Low-level 动作必须调用同一决策规则。
    - epsilon 随机探索、固定风格 rollout 和 DP expert path 保持原行为，避免阻断探索或改写教师轨迹。
    - 模型产物必须持久化动作迟滞配置，推理时不得静默使用不同配置。

11. **作为风险控制者，我希望安全动作优先于持仓迟滞。**
    - 当前动作因强平、涨跌停、保证金或其他环境约束而不可用时，不得因为迟滞继续保持。
    - 环境要求的平仓或风险动作优先执行。
    - 错误的初始仓位仍可在 Q 优势通过门槛时正常平仓或换向，不引入最短持仓时长。

12. **作为实验负责人，我希望改良效果能够按市场状态归因。**
    - 三组消融必须对全部 16 格报告净收益、步骤数、换仓次数、换仓率、手续费、滑点和最大回撤。
    - 重点发布指标是低波动两档×强负/强正斜率四格的合约等权宏观结果。
    - 高波动格和全验证集同时作为非回归观察面，不能只报告目标四格。

## Implementation Decisions

1. **新增七个市场状态锚点 State Feature。** 价格输入使用严格为正的 Bar close，令 \(y_i=\log(p_i)\)，横轴为窗口内递增的 Bar 序号：
   - `log_price_slope_48`、`log_price_slope_96`：对应窗口上 \(y\) 对 Bar 序号的 OLS 每 Bar 斜率。
   - `trend_to_noise_48`、`trend_to_noise_96`：OLS 斜率除以同窗口 Log return 的总体标准差，分母下限为 \(10^{-8}\)。
   - `signed_efficiency_48`：窗口净 Log 变化除以逐 Bar Log return 绝对值之和，分母下限为 \(10^{-8}\)，结果限制在 \([-1,1]\)。
   - `trend_r2_48`：同一 OLS 的 \(R^2\)，常数价格窗口返回 0，结果限制在 \([0,1]\)。
   - `log_return_vol_quantile_192`：当前 48 Bar Log return 波动率在最近 192 个可见 48 Bar 波动率中的经验分位数，结果限制在 \([0,1]\)。

2. **Warm-up 与数值规则。** 新增特征遵循现有滚动 State Feature 的有限值输出约定，窗口不足时输出中性值 0；二维统计和条件指标必须排除不足 48 Bar 的步骤，96/192 窗口特征各自的指标还要排除自身未成熟步骤。所有除法使用明确的 \(10^{-8}\) 分母下限，生成后继续接受 NaN Validation 和 Scale Save；这些特征不是 `Base_Time_feature`，不得跳过缩放。

3. **二维统计状态与 Dynamic Label 完全分离。** 统计斜率使用 `log_price_slope_48`，统计波动率使用 48 Bar Log return 总体标准差。两轴分别在全部训练合约的可用步骤上拟合 25%、50%、75% 行级四分位阈值，并共享给所有合约和 valid。格编号只是统计区间，不进入 Agent 路由、动作约束或现有 slope/volatility Dynamic Label 目录。

4. **条件指标采用长表产物。** 每个 stage、合约、候选特征、预测窗口和二维格记录样本数、IC、RankIC；聚合层同时记录参与合约数、合约等权均值/标准差/中位数、符号一致率和 90% 单侧下置信界。空格必须显式记录，指标值为空而计数为零。现有全局指标列和既有 Manifest 字段保持兼容。

5. **条件保留只补充市场状态锚点。** 现有全局筛选结果与条件通过的锚点取有序并集。目标格固定为波动率格 0/1 与斜率格 0/3 的四个组合。单个目标格至少需要每合约 30 个对齐步骤、至少 3 个合约可评估、RankIC 非零符号一致率不低于 60%，并且按一致方向对齐后的合约等权 RankIC 90% 单侧下置信界不低于现有 `min_abs_ic`，才可补充保留该锚点。某锚点在任一目标格通过即可补充保留；保留原因和通过格必须写入 Manifest。

6. **valid 始终 report-only。** 最终 State Feature 只能由 train 全局规则与 train 条件规则产生。valid 条件指标用于评估衰减和选择实验配置，不能回写 train 特征列表。test 完全不参与该流程。

7. **环境提供逐动作预计换仓成本。** 环境在每个决策时点以无副作用方式估算从当前仓位/杠杆切换到每个可用动作的即时交易摩擦。估算复用实际手续费、盘口成交、深度截断和 Reverse Position best-effort 语义，不改变钱包、持仓、累计费用或随机状态。预计成本为非负的手续费加不利滑点；同动作是 0。

8. **动作迟滞是共享的纯决策规则。** 对已按可用动作掩码处理的 Q 向量，令 \(a^*\) 为最佳候选、\(a_c\) 为当前动作。启用时，仅当 \(Q(a^*)-Q(a_c) > m\,C(a_c,a^*)+b\) 才切换，其中成本倍数 \(m\) 默认 1.0，安全边际 \(b\) 默认 0，且两者必须非负；否则保持当前动作。关闭时退化为现有 argmax。

9. **风险优先与探索隔离。** 当前动作不可用时直接在可用动作中选择最佳候选，不应用保持门槛；环境显式风险处置优先。迟滞只作用于模型贪心动作，不作用于随机探索、DP expert path 或固定策略 rollout。

10. **配置与诊断可审计。** 开关、成本倍数和安全边际随训练配置及模型产物持久化。训练日志和逐步交易明细记录当前动作、原始候选、最终动作、Q 优势、预计成本、门槛与决策原因，并汇总候选换仓数、执行换仓数、被抑制换仓数及估计避免成本。

11. **向后兼容。** 新增条件选择和动作迟滞默认关闭；缺少新 Manifest 字段或新动作配置的旧产物按关闭处理。`fu/30min` 增强实验显式开启，不在验证完成前覆盖现有基线产物。

12. **遵守现有 ADR。** 二维统计格是可观测市场状态的分析分层，不赋予现有 Dynamic Label 编号方向含义，符合 ADR-0008；train-only 共享阈值与方法隔离符合 ADR-0010/0011；Reverse Position 的成本估算和风险绕过必须保持 ADR-0001 的 best-effort 与可用动作语义。

## Testing Decisions

1. **State Feature 算子测试使用现有增强 State Feature 生成接缝。** 以平滑上涨、平滑下跌、常数、含噪趋势和价格等比例缩放数据验证七个公式、边界范围与有限值；使用“先算前缀、再追加未来数据重算”的方式验证前缀不变；非正价格验证 Fail-fast。

2. **Feature Selection 使用现有多合约端到端接缝。** 构造至少四个合约并覆盖 16 格，运行一次完整 train Feature Selection，验证阈值只拟合一次并跨合约共享、16 格显式齐全、计数守恒、条件指标和 Manifest 可复现、通过门槛的锚点按稳定顺序补充保留。再运行 valid，验证复用 train 阈值且不改写 train State Feature。

3. **条件规则覆盖退化输入。** 测试零样本格、少于 30 步、少于 3 个合约、符号一致率不足、下置信界不足和恰好等于门槛等情况；不满足时不得补充保留，也不得因空格使整个流程失败。

4. **预计成本与实际执行做配对测试。** 克隆同一环境状态，一侧调用无副作用估算，另一侧实际执行目标动作；手续费与不利滑点之和应在数值容差内一致，并验证原环境状态未被估算修改。覆盖保持、开仓、平仓、加减仓、允许/禁止 Reverse Position、深度不足和不可用动作。

5. **动作选择纯函数覆盖边界。** 覆盖关闭开关、同动作、优势小于/等于/大于门槛、安全边际、当前动作不可用和非有限输入。非有限 Q、负成本或负配置必须 Fail-fast；并列候选沿用现有确定性 argmax 顺序。

6. **训练/推理一致性使用 Low-level Agent 现有动作接缝。** 给定完全相同的 Q、当前动作、可用动作和成本向量，训练贪心分支、独立 Low-level 测试及路由后的 Low-level 消费者必须返回同一动作。epsilon 随机分支和 DP expert path 的既有测试结果保持不变。

7. **向后兼容回归。** 在新开关关闭、旧 Manifest 和旧模型配置下，选中特征、动作序列和既有测试输出保持原行为；本变更不得修改用户当前已生成的基线数据和模型产物。

8. **离线消融与发布门槛。** 在同一 `fu/30min` train/valid、相同随机种子集合、相同 epoch/checkpoint 候选和相同费用配置下运行：A 现有基线；B 新锚点+条件选择；C 为 B+成本迟滞。报告全部 16 格及目标四格的合约等权指标，并使用按合约/片段配对 bootstrap 给出差值置信区间。只有当 C 相对 A 的目标四格宏观净收益改善、至少三个目标格不下降、换仓次数及实际手续费+滑点下降，且全 valid 与高波动格没有超出预先声明容忍度的退化时，才建议启用增强配置；否则保留实现与诊断能力但维持默认关闭。

## Out of Scope

- 不实施优先级 3 的 16 格采样重平衡、run-level 重采样或 Replay Buffer 优先采样。
- 不修改 Reward 定义、Reward/Advantage 归一化、ADA/KL 权重、DP Q-table 教师目标或 n-step 设置。
- 不引入 RNN、Transformer、TCN 等序列网络，也不改变现有 Qnet 输入维度之外的模型结构。
- 不改变 Dynamic Label 的分段、阈值、语义、二维 Agent 路由或模型槽位填充逻辑。
- 不改变手续费、滑点、盘口撮合、Reverse Position 或强平的实际执行规则；只增加无副作用估算和动作门槛。
- 不使用 test 调参，不以 test 结果决定特征、门槛或默认配置。
- 不自动重写当前已选中的 150 特征 Manifest；必须通过新的、隔离的 Feature Selection 与训练实验产生新一代产物。

## Further Notes

- 当前训练二维分布说明目标四格不是整体稀缺样本，因此本变更优先解决“模型看不清状态”和“低信噪比下换仓过敏”，而不是先做均匀采样。
- 当前 valid 的二维分布与 train 仅轻度漂移，但具体特征存在明显 train→valid 衰减；条件指标必须同时报告 train 和 valid，不能把 train 条件通过误报为泛化成功。
- “市场状态锚点 State Feature”是本规格引入的新领域术语：指因果、尺度无关、直接描述方向/趋势纯度/相对波动位置，且可用于统计分层的 State Feature。若该方案被接受，应在领域词汇表中补充定义。
- Q 值已从包含交易成本的净 Reward 学习；动作迟滞中的预计成本是对函数逼近误差的保守门槛，而不是再次从 Reward 扣费。因此必须通过 B/C 消融单独确认它降低无效换仓而非造成过度持仓。
- 本规格依据当前 `fu/30min` Feature Selection 结果和训练/验证分布形成；重新生成数据后，所有分布数字应作为历史基线保留，新产物必须重新报告实际计数和阈值。
