# AST FineFT 第一轮交易记忆与完整状态实施规格

**Status:** ready-for-agent

日期：2026-10-30。依据用户已确认的设计、参数传递方式及9张工单整理。本文用于实施与验收，尚不代表代码已实现、正式训练已启动或收益已改善。

## Problem Statement

Low Agent目前主要通过实际仓位、持仓收益、最大回撤和持仓时长观察交易过程。空仓时这些值归零，无法区分普通空仓与刚刚实际退出，也无法同时保留多空两方向的退出参照。动作持续和待完成退出等执行条件还可能留在训练或评估循环中，模型输入未充分表达决定下一步转移的状态。

旧DP老师主要按行情时间和previous_action查询，不能区分相同仓位编码下不同的持仓成本、单笔损益或退出历史。仅按模型float32观测去重，也可能合并执行状态实际不同的经验。增加输入维度后，如果独立评估和高层路由仍使用旧模型构造、状态或测试替身，研究者将无法评估新模型。

用户需要将本轮评分3分的交易记忆和完整执行状态贯穿训练、老师、经验回放、独立评估与高层路由，同时保留现有shell传参方式。该工作不应依赖指定历史训练或额外配置系统，也不能通过隐式资金限制改变本轮教学目标。

## Solution

建立可恢复的精确交易状态及共享执行语义，派生统一的18维交易观测。多空退出记忆分别由实际完整退出更新；待完成退出和动作持续状态参与实际转移，并可被模型观察。冷却、连续止损计数和熔断相关五个模型槽位固定为零，本轮不实现对应规则。

教学模式假设资金充足，用传入初始资金作为固定交易损益参考本金，保留真实交易损益、费用和成交限制。精确状态同时用于DP老师行定位及经验去重，模型编码不作为原始执行状态的替代。

预训练、多样化训练、按索引独立评估和高层VAE路由同步迁移模型加载、观测、执行与检验测试。以确定性新维度权重完成真实前向和短轨迹验证，不等待正式重训。精确DP先通过受资源预算约束的短窗口试验，再评估是否可以接入目标训练规模。

2. 作为Low Agent研究者，我希望普通空仓与刚发生实际退出的空仓可区分，以便研究退出后的重入判断。
3. 作为Low Agent研究者，我希望多头和空头的退出记忆独立，以便一个方向的交易不抹去另一个方向的历史。

## Implementation Decisions

### 参数、资金前提与奖励边界

- 继续采用现有shell变量、argparse及主进程/worker参数传递。本轮动作持续P=2、硬止损阈值0.03；实现读取参数，不硬编码数值，不新增特定实验配置系统，也不要求匹配历史checkpoint。
- E_ref取启动时解析的initial_wallet_balance，要求严格正且有限。Train/Valid/Test、合约和reset共用该运行常量，不从运行时余额、权益或旧DP钱包常量重新计算；不另设可与初始资金冲突的参考金额参数。
- 固定初始资金参数不变时，仅改变运行时余额不能改变教学观测、mask、老师Q、经验身份或终止。改变初始资金本身属于改变运行参数，不能据余额不变性测试声称两种不同E_ref的编码相同。
- 教学模式不因保证金不足拒单、不因余额耗尽强平或终止；仍保留预设仓位档位、数量上限、交易时段、盘口/涨跌停、真实费用、滑点和实际成交。真实资金账户的外部约束独立评估。
- 当前单笔累计交易净损益C、历史峰值H、最大回落D以原精度保存；H含零起点，D追踪历史峰值到当前C的最大回落。模型收益与回撤槽位使用C/E_ref、D/E_ref；新开仓开始新单笔，空仓两个槽位为零，真实退出损益仍进入reward。
- 不新增奖励项或loss。按既有拆账规范核验价格损益、真实成本和已冻结塑形，滑点不重复扣除，不以残差补账。固定分母指标是主动口径调整，不宣称数值等同旧legacy指标。

### 精确状态与18维观测

- 精确快照覆盖实际仓位数量、杠杆、持仓成本、浮盈亏、未裁剪持仓时长、C/H/D、多空退出记录、pending及原因、持续剩余步与目标动作，以及禁用规则的零值字段；行情路径由不可变数据身份与绝对行位置引用。
- 交易向量顺序固定为：仓位敞口、单笔收益、单笔最大回落、持仓时长、逆向价格浮亏率、多头退出存在位、多头退出年龄、多头退出后价格变化、空头退出存在位、空头退出年龄、空头退出后价格变化、多头冷却零槽位、空头冷却零槽位、连续止损零槽位、有限熔断零槽位、永久熔断零槽位、pending、动作持续剩余步。
- 保留原有4个槽位，新增14个原评分3分槽位；其中5个固定为零，因此本轮有效新增非恒定字段为9个。previous_action、市场/时间及动作mask保持独立入口，不计入18维宽度。
- previous_action按实际仓位/杠杆映射，不是上一条未成交命令。请求合法性与真实可成交性区分，mask不能代替持续剩余步或待退出状态。
- 逆向价格浮亏率为非零仓位下max(0,-unrealized_pnl)/(abs(q)*当前mark price)，与硬止损口径一致；零仓不计算除法。持仓时长沿用既有归一化窗口与截顶编码。
- 退出年龄取当前步减退出步，以256步截顶后归一化；原始退出步不截顶。价格尺度为最近18个一步绝对价格变化均值与tick size的较大者，需要19个可用价格；预热不足不采样。
- 多头退出价格变化对当前价格减退出成交价按退出决策时尺度归一化后使用tanh(x/5)，空头对价格差取反。尺度通过退出步前一行回查，不用当前波动率替代，不新增独立尺度历史或动量信号。
- 模型值最终为float32；精确状态保留执行器原精度。统一正负零、固定字段顺序、dtype、shape与字节序，拒绝NaN/Inf；不存在的退出事件其相关字段归零。

### 成交、退出记忆与状态生命周期

- 决策状态为此前成交和计时已更新的决策前状态，下一状态由实际成交更新。非零仓位实际归零才写完整退出事件；请求Flat、止损触发或部分减仓均不等于完整退出。本轮不引入一步反向开仓或异步挂单系统。
- t到t+1成交完成的退出记为exit_step=t+1，首次空仓观测退出年龄为0；退出价取完成退出的该次转移实际成交加权价，不跨步累计前期部分减仓价格。
- 多头退出只覆盖多头记录，空头退出只覆盖空头记录；新开仓不清除上次退出，无TTL。专家身份改变不等于交易历史reset。
- 策略或硬风险请求退出未完成时锁存pending及原因，继续请求完成退出，不允许撤回后加仓；硬止损可覆盖策略原因。真实完成退出只写一次事件，不重复记录止损退出。
- 持续状态同时保存剩余步和目标动作。新非空仓持续决策后剩余P-1，后续有效步递减；硬风险/pending立即打断并清空持续状态。P限制请求，不保证成交。
- 冷却、连续止损计数与熔断状态始终为零，不递增、不计时、不约束重入。保留格式不意味着实现状态机。
- episode/reset、合约切换、Train/Valid/Test独立起点清除交易记忆；纯行情预热不继承交易历史。显式连续恢复必须恢复完整快照。非零initial_action评估初态的成本、时长和单笔损益须按一致环境语义初始化。

### 精确DP老师与监督接口

- 老师按数据身份、绝对行情步和精确状态键定位整行；候选动作仅选列。状态键包括契约保留的原精度字段，不能从18维编码反推，不能回退旧时间与previous_action表。
- 每个合法动作通过共享执行器计算即时reward、下一状态和终止，单步gamma递推仅在下一状态合法请求中取max；持续目标、pending和拒单均是真实转移。终点与训练同结算，无额外免费平仓。
- 离线老师可读未来路径计算Q，学生观测、独立评估和高层路由不查询未来老师。不同退出记忆不必然产生不同最优Q；状态差异测试不能强制标签差异。
- 精确状态稀疏存储不保证计算可行。依次试验16、32、64个有效转移步，单次至多250,000个唯一精确状态、2 GiB状态存储、60秒DP计算时间，任一触顶中止本次及自动扩大窗口。
- 存储统计包括可恢复快照、内容索引、Q行和递推缓存，另报告峰值RSS；计算计时覆盖状态展开与回溯，数据读取和预热单列。报告数据坐标、初态、实际参数与触顶维度。
- 完整展开并完成递推后原子发布有效行；缺行标记teacher_label_available=false，仅屏蔽该样本教师loss，TD照常，报告覆盖率。没有有效标签不得填零或使用旧表替代，完整监督验收要求计划监督集合全部可定位。
- 超预算保持明确失败，不自动删维、分桶或改固定策略rollout。短窗口通过只证明该窗口可计算，不证明正式训练episode规模可行；另设近似老师必须另行设计和验证。

### 经验定位、去重与保留

- 当前和n-step终点均携带数据身份、绝对step、精确状态键及可恢复快照引用。快照内容与数据映射随经验导出，稳定内容hash只作为索引，须可恢复并核验冲突，不用进程随机hash。
- teacher_state_key与exact_state_digest采用同一原始字段集合、序列化及值；不存在两套不一致的精确状态身份。teacher行键不包括当前请求动作、未来动作路径或累计reward。
- 起始组D由合约/行情位置、模型实际输入摘要、精确状态摘要和请求动作组成；O由n-step累计回报、实际步数、有效bootstrap折扣、终止/截断及终点行情、观测和精确状态组成。同分格内D/O全部相同才合并。
- 模型float32相同但精确交易状态不同不能合并；相同物理内容来自不同worker或episode仍可合并。老师Q、标签是否已存在、优先级和采集误差不决定环境经验身份。
- 保留同组最多4种O、驻留重复合并、第5种不同O用独立seed RNG随机替换、满格FIFO与索引回收。不按收益择优，不宣称全历史等概率蓄水池；报告组数、重复率、FIFO与组内替换次数。
- 完整/compact IPC及CPU/GPU replay语义一致。沿ADR-0065使用满窗非终止gamma的n_actual次方，真实终止和既有短窗关闭bootstrap时为零；显式区分terminated与truncated但不改变既有短窗策略。

### 模型、训练、独立评估与高层路由迁移

- 修改交易环境及其初始化、Qnet/ensemble、rollout/next observation、预训练、多样化训练、常驻worker、IPC和replay，使18维输入与精确状态信息贯穿采集到更新。旧产物形状或语义不兼容时明确拒绝，不静默补零。
- 按索引独立评估入口test_agent_index.py为明确范围：模型构造与加载、按context真实前向、环境及initial_action初始化、共享动作持续与pending、实际交易循环、明细和汇总指标，以及shell入口均须迁移。平均评估等共享调用者须同步检查，不能留下旧维度入口。
- 高层VAE路由入口vae_routing_util.py为明确范围：共享/按槽位专家加载、实时18维输入、专家切换时交易记忆保留、执行状态同步、跨合约reset、shell和相关检验均须迁移。
- 本轮路由调用链显式传入P=2、止损0.03、初始资金并关闭冷却/熔断，避免路由旧默认重新启用规则。其他既有高层调用保留其可配置行为，不全局删风控或改历史默认。
- 路由OOD、空槽/非主力防御与专家保持/切换机制保留；其产生的实际退出也更新共享记忆。独立Low Agent教学环境不因此增加路由选择条件，也不重训或改造VAE。
- 先扩展可恢复接口，再逐项迁移；仅在确认无调用者后删除临时旧接口。工单状态ready-for-agent表示定义已完整，实际开工仍受阻塞关系约束。

## Testing Decisions

### 主要测试入口

以现有环境初始化、reset和step为最高公共行为入口：在固定可解释行情上，导出/恢复决策状态，提交请求，比较实际成交、损益、合法请求及下一观测。该入口由训练、老师、独立评估和路由执行适配器共用，优先复用现有成交与观测测试基础，不为每层额外建立平行模拟器。

网络、replay和DP在该行为证据上做必要的接口验证；真实模型前向、经验保存恢复与老师数值递推不能由纯环境测试替代。沿用用户已经确认的字段值、真实状态演化、评估输出和路由测试要求，不再发起测试设计访谈。

好测试比较可观察行为及结果，不绑定私有缓存、具体类布局或重复实现相同公式来得到自证结论。4维fixture、stub和真实网络用例必须共同迁移；只把长度改成18、mock掉全部前向或仅断言不抛异常都不构成验收。

CPU真实前向、短轨迹及小批更新为基础验证。GPU可用时覆盖真实设备路径；没有GPU则明确列为未验证。DP规模测试是资源实验，不等于策略训练；短程集成更新不构成收益证明。

最终报告列出实际通过的入口、测试范围、跳过或不可用路径、标签覆盖率、资源触顶情况和已知限制。相同快照与请求在各路径应产生一致转移，但不要求不同决策器选择相同动作。

## Out of Scope

- 模型额外的1/2分字段：账户余额/权益/保证金等输入、退出历史原因编码、入场成本偏离和自定义动量差；执行器恢复必需的精确成本和pending原因仍保留。
- 冷却和熔断状态机、连续止损计数更新、追踪止损、账户回撤停机、日亏限制，以及新造的退出/重入奖励或loss。
- 额外配置系统、特定实验目录或固定初始资金金额、历史训练匹配、旧权重/经验静默迁移。
- 新RNN/Transformer结构、VAE重训、专家选择/门控算法重设计、其他既有高层实验风控的全局改写。
- 一步反向开仓、异步订单系统、未定义的撮合扩展；已存在的真实成交约束继续生效。
- 预算不足时未经设计验证的近似老师、删维分桶、旧表回退或固定策略rollout替代。
- 正式模型重训、自动超参数搜索、收益结论、实盘发布或真实账户资金限制改造。
