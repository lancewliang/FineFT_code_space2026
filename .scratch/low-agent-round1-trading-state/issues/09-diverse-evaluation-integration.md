# 09: 打通并行训练、独立评估与高层路由并完成迁移验收

**What to build:** 让常驻worker采集、多样化训练更新、按索引独立评估及高层VAE路由共同消费一致的新状态，完成shell驱动的短程集成验证；完整状态老师服务训练监督，独立评估和路由无需查询未来老师。

**Blocked by:** 06: 让预训练按经验完整状态读取老师监督；07: 迁移按索引独立评估入口及其检验测试；08: 迁移 VAE 高层路由对新 Low Agent 状态的消费。

**Status:** ready-for-agent

用户已确认生成本工单。依据：第一轮状态契约第7节及 ADR-0065/0066；继承04的IPC/replay能力与06的老师查询能力。

- [ ] shell传入的P、止损阈值、初始资金从主进程一致传至常驻worker、教学执行器、老师和独立评估；本轮P=2、止损3%，不新增特定配置系统或历史训练依赖。
- [ ] 多worker采集到主进程采样更新的18维观测、next observation、精确快照引用与老师行可完整追踪；worker复用和参数重配不串合约/分区状态。
- [ ] 多样化训练使用同一完整状态老师查行和缺标签掩码，覆盖率与DP预算报告可见，不用旧老师维持表面可运行。
- [ ] 对齐本轮执行参数和请求动作，相同快照在训练、老师、按索引独立评估及高层路由执行后产生一致成交、reward、mask及下一状态；不要求不同决策器选相同动作。只改变运行时余额不影响这些结果。
- [ ] 串行/多进程、完整/compact、CPU/GPU可用路径完成针对性回归；缺少GPU时如实标记未验证，不声称全部路径通过。
- [ ] 独立评估和高层路由是显式交付项，分别完成新维度checkpoint加载与真实前向，不得只验训练。移除已无调用者的临时旧接口，所有新入口拒绝不兼容旧checkpoint/replay。
- [ ] 给出短程集成与资源验证结果及限制；不自动启动正式重训或以冒烟更新宣称收益提升。
