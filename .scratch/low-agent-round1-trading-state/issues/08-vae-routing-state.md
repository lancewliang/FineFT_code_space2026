**What to build:** 让高层VAE路由能够加载新18维Low Agent专家、按实时交易状态推断并执行到下一步，使专家切换、动作持续和规则处置后的模型输入与实际持仓一致。

**Blocked by:** 03: 让单进程 Low Agent 观察双向退出记忆与完整执行状态。

**Status:** ready-for-agent

用户已确认生成本工单。用户明确指定范围：`FineFT/RL/DiHFT/high_level/vae_routing_util.py`，以及其模型加载、路由调用入口、shell参数传递和相关检验测试。本项可与04/05/06/07并行；不要求重训VAE或另改专家选择算法。

- [ ] 迁移共享/按槽位的Low Agent模型构造和权重加载，专家推断真实消费18维trading_info；字段顺序、归一化、dtype/device及checkpoint维度校验与训练一致，不用旧4维权重或静默补零维持运行。
- [ ] 路由推断读取当前实际仓位、双向退出记忆、单笔损益、pending与持续目标；同合约普通专家切换不清除交易历史，跨合约、数据分区、独立评估reset正确隔离。
