# 02: 打通资金充足教学模式与固定本金单笔损益

**What to build:** 通过现有 shell/CLI 参数进入教学环境、单进程采集和独立评估，使用传入初始资金作为固定交易损益参考本金，使同一交易轨迹不因运行时账户余额变化而改变动作可行性和交易观测。

**Blocked by:** 01: 为真实交易转移提供可恢复的精确状态。

**Status:** ready-for-agent

用户已确认生成本工单。依据：第一轮状态契约第1.1–1.3、2、3节及既有执行拆账规范；不新增损益塑形。

- [ ] E_ref 从本次解析的初始资金读取一次，严格为正且有限，贯穿环境、采集和评估；不单独硬编码金额或新增可冲突的参考金额配置。
- [ ] 单笔累计净损益 C、峰值 H、最大回落 D 可恢复；原收益/回撤槽位使用 C/E_ref、D/E_ref，新开仓重置单笔，空仓归零，实际平仓损益进入 reward。
- [ ] 固定初始资金参数不变，仅改变运行时余额，不能改变观测、mask、转移或终止；教学模式不因保证金不足拒单或因余额耗尽强平。
- [ ] 仓位档位和数量上限、盘口/涨跌停、真实成交价格、手续费、滑点和基线塑形语义保留；滑点不得重复扣除。
- [ ] 开仓、同向加减仓、持有、退出的损益与已有执行拆账证据对账；无残差补账，固定尺度变更不宣称等同旧资金分母指标。
- [ ] 真实资金账户的外部限制与教学模式边界清楚；参数沿用 shell、argparse 和 worker 参数传递风格，不引入新的配置系统或历史训练前置条件。


**范围依据：** [已确认实施范围与依赖](../spec.md)。
