# 01: 为真实交易转移提供可恢复的精确状态

**What to build:** 先扩展现有执行路径，使一次交易决策前的状态可导出、恢复，并在恢复后重放同一动作得到相同成交、损益、合法动作和下一观测。保留旧调用方式直至后续迁移完成，为完整状态老师和经验身份提供共同依据。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

用户已确认生成本工单。依据：第一轮状态契约第4、5节及 ADR-0065；扩展阶段不改变交易行为。

- [ ] 快照保留恢复下一交易转移和观测所需的原精度状态及行情定位；单笔损益摘要、持仓成本、退出记忆、待退出和持续目标均有明确字段与版本。
- [ ] 原精度序列化固定顺序、dtype、shape、字节序，统一正负零，拒绝 NaN/Inf；无退出事件时该方向字段规范为零。
- [ ] 从同一快照重复恢复并执行同一请求，成交结果、费用、浮盈亏、下一观测与合法请求一致；实际仓位与请求动作区分明确。
- [ ] reset、合约切换及数据分区隔离不继承交易记忆；显式连续恢复保留完整状态。
- [ ] 扩展阶段现有调用者仍可运行；后续新语义不会被自动伪装成旧快照。


**范围依据：** [已确认实施范围与依赖](../spec.md)。
