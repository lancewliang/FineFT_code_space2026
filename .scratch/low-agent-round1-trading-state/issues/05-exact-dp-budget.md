# 05: 从完整快照构造受资源预算约束的精确 DP 老师

**What to build:** 对短行情窗口中的完整交易快照，经同一执行器展开合法动作、精确递推并查询整行动作Q；给出16/32/64步规模报告或明确的预算失败。

**Blocked by:** 03: 让单进程 Low Agent 观察双向退出记忆与完整执行状态。

**Status:** ready-for-agent

用户已确认生成本工单。依据：第一轮状态契约第4、4.1节；本项可与04并行，不依赖经验池实现。

- [ ] 使用df身份、时间行、原精度保留状态定位行，候选动作只选列；不能按旧时间×previous_action表替代完整状态。
- [ ] 每个合法动作通过共享执行器得到 reward、next state 和终止；递推使用单步gamma和下一状态合法请求集合，拒单、pending和持续目标按真实状态演化。
- [ ] 终点结算与教学环境一致，无额外免费平仓；未来路径只供离线老师，学生输入不读未来。
- [ ] 从小型可穷举案例逐动作验证Q与合法位；仅改变运行时余额不改变Q，退出记忆不同不强制要求Q必然不同。
- [ ] 依次试验16、32、64个有效步；单次最多250,000个唯一精确状态、2 GiB状态存储、60秒DP计算，任一触顶即停止本次及自动扩窗。
- [ ] 预算报告覆盖可恢复快照、索引、Q行和递推缓存，另报峰值RSS及读取/预热开销；不完整根状态不发布有效标签。
- [ ] 超预算明确失败，不删状态、分桶、填零或改固定策略rollout；短窗口通过不冒充正式训练episode可计算。
