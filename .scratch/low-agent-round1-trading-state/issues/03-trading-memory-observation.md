# 03: 让单进程 Low Agent 观察双向退出记忆与完整执行状态

**What to build:** 从 shell 参数驱动的真实执行，到18维交易观测、Q 网络决策和单进程 TD 冒烟验证，打通“开仓—持有—请求退出—实际退出—重入”的完整路径；普通空仓和刚退出空仓可被模型区分。

**Blocked by:** 02: 打通资金充足教学模式与固定本金单笔损益。

**Status:** ready-for-agent

用户已确认生成本工单。依据：第一轮状态契约第2、3、5节；只做原有槽位与评分3分的新增项。

- [ ] TRADING_INFO_DIM=18，严格按契约保留行顺序编码为 float32；previous_action、市场/时间输入和动作 mask 维持独立入口。
- [ ] 多空退出记忆各自保留存在位、退出步与实际成交价；只有非零仓位实际归零才写记录，部分减仓和退出请求不写完整退出事件。
- [ ] 退出事件发生于 t 到 t+1 时，首个空仓观测退出年龄为0；方向间不覆盖，新开仓不清除退出历史，无 TTL，步数编码到256后饱和而原始值保留。
- [ ] 退出后价格变化按契约的因果尺度和 tanh 编码；尺度由退出步回查，19个价格预热不足不采样，不引入自定义动量信号。
- [ ] 待退出被拒或部分成交时仍持真实仓位，锁存原因并持续退出，禁止撤回后加仓；硬止损优先于持续动作，完成退出只产生一次事件。
- [ ] 持续动作读取传入参数，本轮P=2；精确剩余步和目标动作都可恢复，请求合法性不冒充成交保证，不引入一步反手。
- [ ] 止损阈值读取参数，本轮0.03；浮亏率口径与执行器一致。M22–M26与T22–T25始终为零，不实现冷却/熔断、不因历史止损限制重入。
- [ ] 单进程网络决策、next observation 和小批 TD 更新消费同一18维输入；新路径无有效完整状态老师时显式屏蔽教师 loss，不回退旧老师。
