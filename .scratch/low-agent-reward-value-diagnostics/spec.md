# Low Agent 真实成本、塑形与动作价值诊断

2026-10-29 用户确认 Q1–Q4 推荐、Q5 第一级。实现及使用方式见 `docs/specs/low-agent-reward-value-diagnostics.md`；决策见 ADR-0067。

验收：八项拆账可复算；普通执行净权益与实际成本对账，奖励与明确塑形及缩放对账；不得以残差补账。逐决策三动作 Q 与动作可用性、请求、实际成交、checkpoint、即时方向惩罚差可关联。持续动作不复用旧 Q。训练详细记录可配置采样，默认关闭。默认奖励与动作选择保持，方向惩罚关闭配置可用于配对消融。

本轮不启动 R0/R1 重训；不生成反事实经济标签，不宣称网络 Q 的因果分解。既有强平奖励不一致须显式报失败。部分成交偏离离散动作网格的执行限制不由本任务重构。
