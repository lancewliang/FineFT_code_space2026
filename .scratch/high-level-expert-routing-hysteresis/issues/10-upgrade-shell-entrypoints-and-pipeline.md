## 已确定的验收范围

- [ ] 四个原 shell 调用新实现并无损消费对应配置；总控传递同一实验/配置身份，后续默认值不能覆盖最佳 Trial 参数。
- [ ] 总控无参数默认执行 1–10，只跑验证时显式指定 `1-9`；显式支持第 10 步、`7-10` 及 `-s 7,8,9,10`，步骤清单、帮助和 README 对应一致。第 10 步只消费已冻结配置，test 结果不反馈选参。
- [ ] 所有依赖步骤在真实任务及必需诊断/审计完成后才推进；失败、中断、配置发布不完整时阻止后续步骤，不复用旧目录制造成功。
- [ ] 四个子 shell 统一以前台完成态返回，移除仅启动内部后台任务便成功退出的分支；总控同步等待。外部后台启动不改变配置、日志、失败或完成语义，内部并行任务仍须等待并核验终态。
- [ ] 真实退出状态可追踪到总控；INT/TERM 终止并回收本次启动的任务，避免孤立后台任务继续写入。
- [ ] 子 shell 和总控实际运行于 finetf；激活失败明确拒绝。含空格的路径和数组参数完整传递，所有执行方式语义一致。
- [ ] `--list`、`--dry-run` 不启动任务或修改权限/产物，展示准确命令计划、配置、阶段与目标日志；日志依据解析后的品种、实验、阶段和用途生成，前台也有可定位日志。
- [ ] 按既有契约隔离新版/历史产物及 valid/test、main_sub/final；续跑核验前置产物身份，不自动补跑训练或隐式选择旧结果。
- [ ] 用受控命令替身验证步骤解析、顺序/等待、非零退出、信号中断、日志路径和预览无写入；本票不运行真实训练、寻优或回测。
