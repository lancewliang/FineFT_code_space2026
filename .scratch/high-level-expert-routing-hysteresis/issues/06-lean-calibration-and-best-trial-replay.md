# 06: 接入固定评分下的轻量校准与最优回放

**What to build:** 研究人员能够在独立校准段仅调整迟滞参数，复用既有只读评分缓存与轻量 trials，并把最优参数完整重载后回放一次，得到可审计的完整结果。一次小型、受控的公开入口集成场景即可验证搜索、选参、重载和落盘闭环。

**Blocked by:** 04 — 交付可追溯的逐步路由审计；05 — 贯通冻结实验配置与最终评估重载。

**Status:** ready-for-human

依据本功能实施规格与 ADR-0062、ADR-0046。04 提供完整回放证据，05 提供冻结配置、独立时间边界及缓存状态隔离。

- [x] 新策略搜索空间实际采样两轴 E、退出比率、共享 Δ 和正整数 K；派生两轴 H 并记录。搜索范围通过有效配置提供，不在此票捏造最优数值。
- [x] VAE 与专家版本、参考分布、两轴评分窗口及衰减参数在全部 trials 中保持固定，不沿用历史搜索流程继续采样评分窗口或衰减；其他既有风险与执行设置保持本实验固定配置。
- [x] Trial 参数、结果记录、最优参数导出、重载与最终评估完整保留策略标识/版本、固定评分设置及全部迟滞参数；缺失或不兼容配置明确失败，不能退回默认值继续回放。
- [x] 校准仅使用经 05 验证的独立校准段，拟合/专家选择数据和最终测试结果不参与本轮选择；在公开准备入口验证污染区段会被拒绝作为正式独立校准。
- [x] Trials 复用只读 Routing Quantile Cache，各自独立初始化路由状态；轻量模式不落盘大历史与完整日度审计，只保留选择所需的指标和参数记录。
- [x] 搜索完成后，将最优 Trial 的确切参数应用到一次开启全量产物的回放；输出完整路由审计、真实推断及执行证据，并保持与该 Trial 相同的评分及执行协议。
- [x] 小型受控集成验证从公开搜索入口至最优回放：确认全部五个搜索维度被使用、固定评分字段未变化、选中值未丢失、一次完整回放被触发，且轻量模式没有全量历史写出。
- [x] 相同输入和最优配置下，轻量 Trial 与完整回放使用相同的 `router.test()` 目标函数、冻结评分缓存与执行配置；受控入口覆盖确保最优参数没有在回放时丢失。真实策略数值比较留待具备独立资产后的 07。
- [x] 历史 absolute、hierarchical 的搜索及回放回归场景继续通过；本票不触发模型重训或自动启动大规模研究实验。实际独立历史评估及结论由 07 交付。
