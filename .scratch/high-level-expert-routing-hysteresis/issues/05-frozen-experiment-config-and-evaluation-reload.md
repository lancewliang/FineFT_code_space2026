# 05: 贯通冻结实验配置与最终评估重载

**What to build:** 研究人员能够通过公开配置准备一次固定评分的专家迟滞实验，导出后由最终评估入口完整重载，且不会悄悄退回默认策略或默认参数。实验能证明模型、参考分布、评分协议和时间边界的身份，缓存复用不污染独立运行状态。

**Blocked by:** 01 — 接通专家进入、保持与规则恢复。

**Status:** ready-for-human

依据本功能实施规格与 ADR-0062、ADR-0046。本票可在 02—04 推进期间独立完成配置准备、重载及公开路由一致性验收；实际自动搜索由 06 交付。

- [x] 公开参数解析、有效配置、导出记录及最终评估准备入口贯通策略标识与版本、两轴 E、退出比率、派生 H、共享 Δ 和 K；导出后重载得到同一有效配置，不缺值回落默认值。
- [x] 记录并冻结两轴 VAE、专家模型与 Selection Manifest、参考分数分布、两轴评分窗口和两轴衰减参数的实验身份；有版本或配置不兼容时明确报错，不生成貌似有效的正式评估。
- [x] 在公开边界校验新策略 H/E、退出比率、Δ、K 的合法性；历史策略仍保留原有参数表达及解析语义，不将历史配置静默解释为新策略。
- [x] 实验准备记录按时间先后分开的拟合/专家选择、校准、最终评估区段与来源证据。拟合或专家选择区段复用于校准时不能标记为独立；需先纠正切分或明确阻断正式独立评估。
- [x] 最终评估使用冻结的已选配置，测试表现不进入选参过程；配置快照和身份记录足以识别测试前后发生的参数变动。
- [x] Routing Quantile Cache 继续只保存只读评分数据，缓存与固定模型、参考分布及评分协议匹配；不共享包含当前专家或候选计数的路由对象。
- [x] 对同一组冻结分位数，仅改变缓存读取与同协议评分输入来源，通过公开路由得到相同专家选择、最终动作与公开归因。不得用两组随机模型输出的差异代替缓存一致性验证。
- [x] 多合约、跨 Trial 重用缓存时，各 rollout 初始化和重配置都重置路由状态；通过交错独立运行证明一个运行的候选证据不会影响另一个运行。
- [x] 用公开调参准备及最终评估准备/重载入口验证参数往返与固定评分配置，复用既有缓存、参数加载和最终结果 fixtures；真实大规模校准不属于本票验收前提。

## Comments

2026-10-24 — 已实现冻结实验配置与重载，等待人工审阅。新增 `frozen_experiment.py`，用版本化 JSON 记录完整策略、E/H、退出比率、Δ/K、固定评分、模型/参考分布/特征/选拔清单/实际数据文件哈希，以及拟合、选拔、校准、最终评估时间和来源证据。拟合与选拔允许互相重叠；两者均不得复用于校准，校准不得进入最终测试。公开准备入口检查实际带时区 timestamp、显式 TradingDay 与跨边界重用；缺失证据和版本/内容变化均阻断。

最终入口只从完整 `frozen_config` 重载新策略，不自动发现或混用历史 para/CSV，拒绝显式覆盖冻结参数；回放后再次检查参数和来源并保存 receipt。评分缓存绑定实验/协议/阶段/合约内容身份，以固定 seed、批大小和顺序生成，只读共享，不包含路由状态。历史门控解析保留；基础低层参数解析保留旧的通用参数默认表达，正式准备仍对固定评分证据作严格匹配。

验收使用受控小数据、微型 VAE 与公开调参准备、最终准备/回放及 get_action 入口；包括相同输入的缓存/固定协议路由一致性、独立确认状态、完整往返、污染/变更拒绝、可重复缓存和最终身份落盘。新模块与测试通过 Ruff 检查/100 列格式及 Pyright（新模块零错误/警告）。未运行真实专家训练、实际资产校准、最终绩效评估或部署；现有资产的 TradingDay 污染、选拔/校准重用和共享账户前提仍按 07 保留，不能因本票通过而认证独立研究结论。
