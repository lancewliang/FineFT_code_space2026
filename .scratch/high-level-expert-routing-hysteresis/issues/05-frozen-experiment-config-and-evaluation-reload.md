# 05: 贯通版本化冻结配置与步骤 7–10 重载

**What to build:** 研究人员能够准备联合搜索评分与迟滞参数的专家路由实验，记录每个 Trial 的完整配置，并将最佳 Trial 的全部参数冻结、导出和完整重载，不会悄悄退回默认值。实验能证明模型、参考分布、评分协议和时间边界的身份，缓存复用不污染独立运行状态。

**Blocked by:** 01 — 接通专家进入、保持与规则恢复。

**Status:** ready-for-agent

依据本功能实施规格与 ADR-0062、ADR-0046。本票可在 02—04 推进期间独立完成配置准备、重载及公开路由一致性验收；实际自动搜索由 06 交付。

2026-10-25 最新实施约束：用户解除冻结，步骤 7–10 原文件直接升级。配置解析、公共参数列、筛选器与 `vae_routing_final_result_macro_action.py` 均需消费同一版本化完整配置，不保留旧目录名、旧文本参数及策略推断的兼容分支。见规格与 ADR-0063。

- [ ] 公开参数解析、有效配置、导出记录及最终评估准备入口贯通策略标识与版本、两轴窗口、两轴 gamma、两轴 E、退出比率、派生 H、共享 Δ 和 K；导出后重载得到同一有效配置，不缺值回落默认值。
- [ ] 校准期间固定两轴 VAE、专家模型、Selection Manifest 与参考分布身份，四项评分参数随 Trial 联合搜索并实际参与计算；最佳 Trial 确定后，将其全部评分与迟滞参数冻结。记录参数范围/有效配置，有版本或配置不兼容时明确报错。
- [ ] 在公开边界校验新策略 H/E、退出比率、Δ、K 的合法性；旧策略、旧 schema 或不完整配置明确拒绝，不静默补默认值或解释为新策略。
- [ ] 实验准备记录按时间先后分开的拟合/专家选择、校准、最终评估区段与来源证据。拟合或专家选择区段复用于校准时不能标记为独立；需先纠正切分或明确阻断正式独立评估。
- [ ] 最终评估使用冻结的已选配置，测试表现不进入选参过程；配置快照和身份记录足以识别测试前后发生的参数变动。
- [ ] Routing Quantile Cache 继续只保存只读评分数据，缓存与固定模型、参考分布及评分协议匹配；不共享包含当前专家或候选计数的路由对象。
- [ ] 对同一组冻结分位数，仅改变缓存读取与同协议评分输入来源，通过公开路由得到相同专家选择、最终动作与公开归因。不得用两组随机模型输出的差异代替缓存一致性验证。
- [ ] 多合约、跨 Trial 重用缓存时，各 rollout 初始化和重配置都重置路由状态；通过交错独立运行证明一个运行的候选证据不会影响另一个运行。
- [ ] 原始逐时点分位缓存可在来源身份一致时跨窗口/gamma 只读复用；每个 Trial 用自己的窗口/gamma 重建平滑权重、deque 和预热状态，不复用前一 Trial 的平滑结果。若缓存派生平滑分数，身份须加入四项评分参数与平滑协议。
- [ ] 用公开调参准备及最终评估准备/重载入口验证九维参数往返，最佳 Trial 评分与迟滞配置在回放及步骤 8–10 保持不变；复用既有缓存、参数加载和最终结果 fixtures，真实大规模校准不属于本票验收前提。
- [ ] 升级后的 Optuna、筛选器及 final-result 入口共用带 schema_version 的完整已解析配置；导出后实际构造 expert_hysteresis。CSV/可读文本仅作投影，不通过目录名重建配置，不因任何已解析字段未出现在 params_* 中而丢值。
- [ ] 固定模型、Manifest、参考分布及匹配评分协议的缓存只读共享，使用前核对实验身份；缺失或不匹配的缓存在 expert 命名空间生成或明确失败，不重建旧缓存。最终评估配置及 valid/test 结果不写回旧 VAE 实验目录。
- [ ] 完整配置包含策略与 schema 版本、全部固定与搜索参数、派生 H、study/Trial/目标身份、模型/Manifest/数据时间边界、账户/单位、费用、风险设置及配置哈希；步骤 7–10 重载后一致，不依赖各 shell 原有默认值。
- [ ] 首次校准时解析并冻结有效资金、费用、止损、冷静期、断路器与非主力设置；后续评估显式冲突时报错或另立实验身份。不得在步骤 9 使用 6000、步骤 10 静默切为 5000 等原有默认值漂移。
