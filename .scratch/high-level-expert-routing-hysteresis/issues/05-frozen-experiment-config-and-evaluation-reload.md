# 05: 贯通冻结实验配置与最终评估重载

**What to build:** 研究人员能够通过公开配置准备一次固定评分的专家迟滞实验，导出后由最终评估入口完整重载，且不会悄悄退回默认策略或默认参数。实验能证明模型、参考分布、评分协议和时间边界的身份，缓存复用不污染独立运行状态。

**Blocked by:** 01 — 接通专家进入、保持与规则恢复。

**Status:** ready-for-agent

依据本功能实施规格与 ADR-0062、ADR-0046。本票可在 02—04 推进期间独立完成配置准备、重载及公开路由一致性验收；实际自动搜索由 06 交付。

- [ ] 公开参数解析、有效配置、导出记录及最终评估准备入口贯通策略标识与版本、两轴 E、退出比率、派生 H、共享 Δ 和 K；导出后重载得到同一有效配置，不缺值回落默认值。
- [ ] 记录并冻结两轴 VAE、专家模型与 Selection Manifest、参考分数分布、两轴评分窗口和两轴衰减参数的实验身份；有版本或配置不兼容时明确报错，不生成貌似有效的正式评估。
- [ ] 在公开边界校验新策略 H/E、退出比率、Δ、K 的合法性；历史策略仍保留原有参数表达及解析语义，不将历史配置静默解释为新策略。
- [ ] 实验准备记录按时间先后分开的拟合/专家选择、校准、最终评估区段与来源证据。拟合或专家选择区段复用于校准时不能标记为独立；需先纠正切分或明确阻断正式独立评估。
- [ ] 最终评估使用冻结的已选配置，测试表现不进入选参过程；配置快照和身份记录足以识别测试前后发生的参数变动。
- [ ] Routing Quantile Cache 继续只保存只读评分数据，缓存与固定模型、参考分布及评分协议匹配；不共享包含当前专家或候选计数的路由对象。
- [ ] 对同一组冻结分位数，仅改变缓存读取与同协议评分输入来源，通过公开路由得到相同专家选择、最终动作与公开归因。不得用两组随机模型输出的差异代替缓存一致性验证。
- [ ] 多合约、跨 Trial 重用缓存时，各 rollout 初始化和重配置都重置路由状态；通过交错独立运行证明一个运行的候选证据不会影响另一个运行。
- [ ] 用公开调参准备及最终评估准备/重载入口验证参数往返与固定评分配置，复用既有缓存、参数加载和最终结果 fixtures；真实大规模校准不属于本票验收前提。
