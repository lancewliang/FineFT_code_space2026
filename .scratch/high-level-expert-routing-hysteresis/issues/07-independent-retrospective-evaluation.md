# 07: 完成独立回溯评估与对照报告

**What to build:** 实验负责人能够在独立校准段选定迟滞参数，冻结后完成最终测试，并取得可复现的历史策略对照报告。报告同时呈现路由稳定性、响应等待、真实执行摩擦和净绩效，用实际证据判断效果，不将减少切换本身当作收益改善。

**Blocked by:** 10 — 四个高层 Shell 与流水线总控联调验收（依赖 09、08、06、05 的全链路实现；10 的运行方式已确认，实现验收尚未完成）。

**Status:** ready-for-agent

依据本功能实施规格与 ADR-0062；遵守 ADR-0060 的数据边界、账户和计量契约。本票描述后续实际研究交付，本次生成 tickets 不执行训练、校准、回测或部署。

2026-10-25 最新实施约束：用户解除冻结，步骤 7–10 原文件直接升级、不再向后兼容。本票在 06→08→09 的完整实现上运行独立研究评估；历史对照来自可追溯存档或单独历史代码版本，不要求升级后的流水线保留旧策略执行分支。

- [ ] 在运行前确认模型拟合及专家选择、迟滞校准、最终测试的时间边界与版本证据有效；若仍沿用受污染的旧区段或模型，不认证正式独立结论，并明确列出缺失证据及修复前提。
- [ ] 实际独立校准执行 06 的九维联合搜索，保存选定两轴窗口、两轴 gamma、两轴 E、退出比率、派生 H、Δ、K 及预热规则；模型/参考分布保持固定，正式测试前固化最佳完整配置与实验身份，最终测试结果不能反向修改已选参数。
- [ ] 完成冻结新策略与可追溯历史策略结果的可比对照；历史结果可以来自存档或独立历史代码版本，不将旧产物按新 schema 静默重解释，也不为对照在升级代码中维护兼容分支。使用相同可比数据、模型证据及评分缓存或冻结评分协议，明确剩余差异，不混用评分生成的随机波动解释路由收益。
- [ ] 报告分别统计普通专家替换、专家与规则之间转换、短期切回、规则占比；短期切回的观察口径在看最终测试结果前固定并记录，不以事后挑选口径制造改善。
- [ ] 候选确认等待同时按决策步数与实际时间报告，覆盖首次进入、替换及规则恢复；明确暖机和因历史不足而延迟覆盖的范围。
- [ ] 同时报告真实换手、实际手续费及滑点等摩擦、净收益与最大回撤，保留既有指标定义、账户范围和单位。专家切换不产生额外虚构交易或切换费用。
- [ ] 指标可回溯到逐步路由、Prediction Record、实际执行与账户证据；相同配置重复回放得到一致路由，并通过相关账本及审计一致性检查。
- [ ] 输出对照表和解释性报告，区分行为契约是否满足与绩效是否改善；允许结果显示等待成本、收益下降或回撤恶化，不预设改善幅度或收益保证。
- [ ] 将结果明确标为评分与迟滞联合优化；若单独归因迟滞效果，需使用同一固定窗口/gamma 与评分输入协议作路由消融。记录各 Trial 的预热覆盖及有效评价区间，不能把不同窗口造成的比较区间差异隐藏为迟滞收益。
- [ ] 不在本票悄悄重训专家、修改选拔门槛、费用、Reward Shaping、DP Q 表或账户语义。若独立实验缺乏必要数据或模型，明确保留未完成项，不能用受污染结果替代验收。
- [ ] 实际贯通步骤 7 寻优、8 配置发布/可视化、9 主副同步诊断、10 最终 test，保留阶段、用途、Trial 与配置身份；步骤 9/10 的 test 结果均不反馈选参，不覆盖先前 valid 证据。
