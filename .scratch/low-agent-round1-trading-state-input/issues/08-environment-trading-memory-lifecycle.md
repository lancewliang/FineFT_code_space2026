## 验收标准

- [ ] 新增并严格校验 exit_price_scale_floor 环境参数；先验证当前行情有效位，再计算 max(下限, 当前行统计量)。不重算滚动窗口，不用下限把无效占位变成有效数据。
- [ ] 环境按有效位选择交易起点并记录原始坐标、排除行数与有效行数；有效的后续 slice 从首行可交易。覆盖 reset、初始有仓和无足够转移数据的拒绝；不模拟预热交易。
- [ ] 保持普通观测原四维计算口径；浮亏率 max(0,-U)/(abs(q)*P)，空仓不做除法，多空及非单位仓位覆盖，不额外乘杠杆。
- [ ] 只在该方向实际仓位由非零变零时更新记录；以当次 closed_value/closed_quantity 取成交均价，部分减仓、拒单、开加仓不写完整退出。不新增反手执行能力。
- [ ] 退出时锁存决策行 scale(t)，保存首次可见的 t+1 坐标；首次返回观测时间为 0，下一步 1/256，超过 256 饱和但保留事件；多头上涨、空头下跌为正，按锁存尺度及除数 5 做 tanh。
- [ ] 双方向互不覆盖，重新入场保留，reset 清空；重复编码只读，不重复写事件或递增时长。未来退出时间、非法成交价、非正尺度明确失败。
- [ ] 审计正常、强制处置及全部终止路径，先确定最终执行结果再编码；终止仍持仓保留真实持仓。无成交证据不登记退出，不修改奖励、成交规则、账户或终止判定。
- [ ] 使用实际环境和确定性行情验证退出/拒绝/部分减仓/重新开仓/终止/reset/初始有仓；因果、有效位和原四维回归通过。记录终止前四维由零改为真实编码这一已确认例外。
