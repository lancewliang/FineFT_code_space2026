## 1. 交付目标与范围

让 Low Agent 在保留当前持仓观测的基础上，知道当前持仓浮亏程度，以及最近一次多头、空头实际退出距离现在多久、退出后价格如何变化。

第一批 `trading_info` 从 **4 维扩展为 11 维：原有 4 维 + 浮亏率 1 维 + 多头退出记忆 3 维 + 空头退出记忆 3 维**。字段顺序、类型、公式和生命周期在本文固定。它是交易观测向量，不是可独立恢复整个执行环境的完整状态快照，也不宣称已经满足完整 Markov 性。

本批包含：

- 环境内维护双方向退出记忆、计算新增观测，并正确构造当前/下一状态。
- Qnet、ensemble、串行/并行采集、CPU/GPU replay、compact IPC 的 11 维接入。
- 预训练、多样化训练、独立评估和高层路由中所有使用该模型的输入与加载适配。
- 输入 schema 标识、旧维度拒绝、因果性与端到端传输验收。
- 短程训练验证：真实环境采集、replay 入池和采样、模型前向、真实 learner 参数更新。

本批不包含：DP 老师扩维或重算算法、精确状态 digest/快照库、经验去重算法升级、资金充足教学环境、奖励/损益指标重定义、动作持续规则统一、待退出状态机、冷却/熔断、新交易约束、VAE 特征或路由算法调整、正式训练及收益结论。

replay 仍必须传输完整 11 维向量，既有“模型可见上下文”键自然包含这 11 维；这属于输入链路适配。每组最多 4 个后续、随机轮换、FIFO 和 n-step bootstrap 语义均沿用现状，不新增精确执行状态身份。

## 4. 输入字段契约

`trading_info` 为连续 `np.float32` 一维数组 `(11,)`，learner 张量为 `(B,11)`。顺序如下，索引从 0 开始。新增字段全部只使用当前及过去可用信息。

记号：`q_t` 为实际策略仓位数量，`P_t` 为当前参考价 `current_markprice`，`U_t` 为当前 `unrealized_pnl`；`t` 为 df 内当前观测的绝对行坐标。策略数量使用项目现有口径，fu 为吨，不写成交易所手数。

命名约定：新增字段直接表达观测含义。`last` 指该方向最近一次事件；本契约中的 `exit` 专指实际仓位归零的完整退出；`record_valid` 指记录已存在且可供编码使用，不表示交易信号仍有预测价值或退出刚刚发生。`steps_since` 表示环境步数间隔，`norm` 表示按指定步数归一化；`tanh` 明确价格移动已经过尺度归一化和有界变换，不能当作原始价格差或收益率使用。`rise` 表示上涨取正，`drop` 表示下跌取正，反向移动仍可为负。

原有 4 个字段保留源码名称，计算口径沿用现状；其中 `position_exposure` 具体指有符号策略数量比例，不是名义金额与账户权益之比。下面列出的 7 个新增字段名为实施时的正式名称，公式、维度和张量顺序不因改名而改变。

| 索引 | 字段 | 计算与来源 | 空仓/无历史 | 状态 |
|---:|---|---|---|---|
| 0 | `position_exposure` | `q_t/max(abs(position_list))`；最大允许数量为 0 时沿现实现取 0 | 空仓 0 | 原有 |
| 1 | `single_holding_return_rate` | 原环境计算的 `single_holding_return_rate`，不换分母、不额外裁剪 | 空仓 0 | 原有 |
| 2 | `single_holding_max_drawdown` | 原环境计算的 `single_holding_max_drawdown`，不替换为账户回撤 | 空仓 0 | 原有 |
| 3 | `current_holding_duration_norm` | `min(current_holding_duration/holding_duration_norm_steps,1)`，保留当前字段拼写及正数参数校验 | 空仓 0 | 原有 |
| 4 | `unrealized_loss_to_notional_ratio` | `max(0,-U_t)/(abs(q_t)*P_t)`；持仓时要求正、有限参考价 | 空仓 0，不做除法 | 新增 |
| 5 | `last_long_exit_record_valid` | 本 episode 最近一次多头完整退出记录是否可用，0/1 | 无历史 0；空仓可为 1 | 新增 |
| 6 | `steps_since_last_long_exit_norm` | `min(t-last_long_exit_step,256)/256` | 无历史 0 | 新增 |
| 7 | `price_rise_since_last_long_exit_tanh` | `tanh(((P_t-last_long_exit_price)/last_long_exit_scale)/5)` | 无历史 0 | 新增 |
| 8 | `last_short_exit_record_valid` | 本 episode 最近一次空头完整退出记录是否可用，0/1 | 无历史 0；空仓可为 1 | 新增 |
| 9 | `steps_since_last_short_exit_norm` | `min(t-last_short_exit_step,256)/256` | 无历史 0 | 新增 |
| 10 | `price_drop_since_last_short_exit_tanh` | `tanh((-(P_t-last_short_exit_price)/last_short_exit_scale)/5)` | 无历史 0 | 新增 |

浮亏率与现有止损比例同口径，正数表示亏损，盈利归零；不额外乘杠杆。它继承 `unrealized_pnl` 的现有执行记账含义，不宣称是剔除全部交易成本的纯价格收益。新增该观测本身不触发止损。

多头退出后的上涨编码为正，空头退出后的下跌编码为正。存在位区分“无历史”和“退出后价格刚好未变”；超过 256 步只让时间编码饱和，不自动删除退出事件。原始步号不截顶。

`previous_action`、`avaliable_action`（沿用现有拼写）、时间、RL 市场特征仍走原独立入口。动作编号从现有映射取得，不假定 Flat/Long/Short 的固定整数或动作总数为 3。

### 4.1 各字段向模型表达什么

以下说明是字段的业务含义与设计用途，不代表已经验证其预测价值。字段数值只提供观测条件，不直接构成开仓、退出或奖励规则。

| 索引 | 字段 | 含义与读数解释 |
|---:|---|---|
| 0 | `position_exposure` | 现在实际持有哪个方向、多大仓位。正数表示多头，负数表示空头，绝对值表示相对最大允许策略数量的比例；不是本步请求的目标仓位。 |
| 1 | `single_holding_return_rate` | 当前这段持仓按原环境记账口径累计赚亏多少。正数为收益、负数为亏损；分母沿用原所需资金计算，不解释为固定初始本金回报率。 |
| 2 | `single_holding_max_drawdown` | 当前这段持仓期间，按原环境净值序列和峰值口径曾发生的最大回撤。它描述持仓过程中的历史回落程度，不等于当前浮亏，也不等于整个账户的最大回撤。 |
| 3 | `current_holding_duration_norm` | 当前这段连续持仓已经持续多久。新开仓沿现有规则从 1 步开始；达到归一化步数后为 1，不能再区分更长的持仓。 |
| 4 | `unrealized_loss_to_notional_ratio` | 当前持仓浮亏相对于当前持仓名义金额的比例。值为 0 表示空仓或没有浮亏；结合仓位字段区分两者。它不保留盈利幅度，也不表示历史最大亏损。 |
| 5 | `last_long_exit_record_valid` | 最近一次多头完整退出记录是否有效。0 表示本 episode 没有这条记录；1 表示可解释后面的多头退出时间与价格变化。它不是多头成交次数、盈利标记或当前多头仓位标记。 |
| 6 | `steps_since_last_long_exit_norm` | 最近一次多头完整退出距离当前有多近。实际间隔 5 步编码为 `5/256`；达到 256 步后饱和。它不是距第一次退出的时间。 |
| 7 | `price_rise_since_last_long_exit_tanh` | 相对最近一次多头实际退出成交价，当前价格向哪个方向移动、移动幅度相对退出时尺度有多大。上涨为正，下跌为负；不代表重新开多一定有利。 |
| 8 | `last_short_exit_record_valid` | 最近一次空头完整退出记录是否有效。含义与多头存在位对称，两方向记录独立；不会因为多头成交而自动置 1 或清零。 |
| 9 | `steps_since_last_short_exit_norm` | 最近一次空头完整退出距离当前的步数，经 256 步尺度归一化；不是距最近任意方向成交的时间。 |
| 10 | `price_drop_since_last_short_exit_tanh` | 相对最近一次空头实际退出成交价的方向性价格变化。下跌为正，上涨为负，使正值与原空头方向一致；不代表重新开空一定有利。 |

### 4.2 一个 episode 多次成交时如何更新

“成交”与“完整退出”不同。开仓、加仓、部分减仓以及未成交的退出请求都不更新退出记录。只有实际仓位从该方向非零变成零，才覆盖该方向的最近退出记录。每个方向只保存一条最近记录，不保存完整交易列表。

假设多头完整退出分别在返回观测的第 20、50、90 步可见，空头完整退出在第 70 步可见：

| 观察时点 | 多头存在位 | 多头记忆所指事件 | 多头时间编码 | 空头记忆 |
|---|---:|---|---|---|
| 第一次多头退出之前 | 0 | 无 | 0 | 独立维护，尚无退出时存在位为 0 |
| 第 20 步 | 1 | 第 20 步退出 | 0 | 不受本次多头退出影响 |
| 第 50 步 | 1 | 更新为第 50 步退出 | 0 | 不受本次多头退出影响 |
| 第 90 步 | 1 | 更新为第 90 步退出 | 0 | 仍指向第 70 步空头退出 |
| 第 95 步 | 1 | 仍指向第 90 步退出 | `5/256` | 存在位为 1，时间为 `25/256` |

第 95 步的多头价格变化使用第 90 步退出记录里的成交价与锁存尺度；空头价格变化使用第 70 步退出记录里的成交价与尺度。若第 92 步重新开多，以上两条退出记忆仍保留，直到下一次对应方向完整退出或 episode reset。

### 4.3 为什么保留存在位，以及它的局限

存在位是缺失标记，主要用于消除零值歧义：从未有过多头退出时，多头时间和价格变化均填 0；刚完成多头退出且当前参考价恰好等于退出成交价时，这两个值也都是 0。存在位分别为 0 和 1，模型才能区分两种情况。空头同理。

长 episode 中，两方向一旦都完成过退出，两个存在位就会长期为 1。此后主要由退出时间和价格变化提供信息，存在位不表达交易次数或历史复杂程度。因此保留它们是为了使退出记忆可解释，不应将它们描述为持续变化的独立交易信号。

本批设计的限制如下：

- 只记最后一次退出，不能表达连续胜负、此前多次反复交易或完整持仓历史。
- 超过 256 步后时间编码饱和，300 步与 3,000 步无法通过该时间字段区分；价格参照仍保留，可能已过时。本批不新增 TTL，记忆有效期留待后续消融验证。
- reset 后“没有记录”仅表示该 episode 没有交易记忆，不表示该合约在更早时间没有交易。人为切分 episode 会改变记忆可用性，实验应保持一致的起点和 reset 规则。
- 当前源码为这些观测提供了实现所需的数据，但尚无训练证据证明退出记忆提高策略表现。建议后续比较原 4 维、“原 4 维 + 浮亏率”的 5 维与本规格 11 维输入，保持其他条件一致，检验退出记忆的增益；正式对照重训不属于本次短程验证范围。

## 5. 价格尺度与因果时点

新增退出价格变化采用参考文档的 18 个一步绝对变化尺度：

```text
scale(t) = max(exit_price_scale_floor, mean(abs(P[i] - P[i-1]), i=t-17..t))
```

命名约定：`exit_price_scale_floor` 专指退出记忆的价格尺度下限，属于实验配置；`tick_size` 保留用于交易所最小变动价位，二者不共用配置字段。本功能未实施，无须提供旧参数别名。

它需要截至 t 的 19 个同合约参考价，不是 ATR。`exit_price_scale_floor` 通过命令行参数 `--exit_price_scale_floor` 显式配置，作为本公式的价格尺度下限，由环境初始化、采集 worker、评估和路由入口透传。缺失、非正数或非有限值明确失败；同一次运行的配置须一致，不从标准化 RL 特征反推。

用户已确认本次 fu 实验使用 `--exit_price_scale_floor 5`，单位为元/吨。这是实验尺度下限覆盖值，不得将其写成交易所规定的最小变动价位。[上期所燃料油期货业务细则第五条](https://www.shfe.cn/regulation/exchangerules/productrules/202512/t20251231_829966.html)规定的最小变动价位为 1 元/吨；实验覆盖值、配置来源与交易所规格应分别标明。当前 Base_Env 未提供该参数，接入它是本批新增工作。

在 `s_t -> s_(t+1)` 中，环境使用决策时可用盘口执行动作：

1. 保存旧实际仓位与 `scale(t)`。
2. 读取实际执行结果。若旧仓位非零而新仓位为零，记录所属方向退出。
3. `exit_price = closed_value/closed_quantity`，要求成交数量为正、均价正且有限；不加减手续费，不用 `reference_price` 或 `P_(t+1)` 代替成交价。
4. `exit_step=t+1` 是该退出在返回观测中的可见坐标，不表示成交使用了 t+1 的未来盘口；`exit_scale=scale(t)` 在事件发生时锁存。
5. 用更新后的记忆构造 `s_(t+1)`：首次空仓观测的距退出步数为 0，但价格变化可能非零，因为参考价与成交价不同。

本批直接保存退出尺度这一观测缓存，避免跨 worker 或截取窗口后回查错误的 df。它不涉及老师状态键的最小化问题；与原老师方案“不单独存尺度”的选择不同。

特征工程在同合约、同 Train/Valid/Test 分区内，以截至当前行的 19 个参考价预计算 18 步平均绝对变化，并记录完整窗口有效性。先计算再切随机片段，切片保留辅助列和原始行坐标，无须为运行期重算尺度额外传递 18 行历史前缀。分区首部历史不足的前 18 行不可交易；记录有效起点、排除行数及有效行数。随机切片不重复丢弃其前 18 行，比较实验使用相同交易起点；老师表与 compact 索引保持对齐。禁止跨合约、跨分区补齐、未来值、反向填充或缩短窗口；辅助列缺失、可交易行无效或数据不足时明确失败。

尺度只取截至决策行的数据。已知退出历史时，后续价格变化始终除以锁存尺度，不随当前波动率重新缩放。跨休市按环境行步数计算间隔，不声称是自然分钟或有效交易时长。

### 5.1 已确认：行情统计预计算，交易观测动态维护

`scale(t)` 只依赖同合约历史参考价和尺度下限，与策略动作、仓位、成交和退出事件无关，因此可以在特征工程阶段因果预计算。计算整张表不等于读取未来：每一行仍只允许读取该行及过去 18 行，并遵守同 Train/Valid/Test 分区隔离。

用户确认采用：特征工程输出未标准化、保留原价格单位的 18 步平均绝对变化辅助列；环境读取当前行数值，与实验配置下限取 `max`。保留 `--exit_price_scale_floor` 实验配置语义，调整下限不必重建特征数据。辅助列可以为零，必须有限且非负；完整窗口有效性独立判断，无效预热行用 0 加 false 表示，详见第 5.2 节。环境应用正下限后，最终尺度必须正且有限。最终 `scale(t)` 不作为绑定某个实验下限的固定特征产物。

辅助列应保留在行情载体中，与 RL/VAE 特征选择和标准化隔离；不能经过 RobustScaler、对数变换、截断或特征筛选，也不自动增加模型市场输入维度。按同合约、同分区、相同时序先计算再切随机片段；完整窗口不足的前 18 行保持不可交易，不用零、未来值或跨分区历史填补。切片、老师表和 compact 行情索引必须保留对齐。只有已证明每行有合格尺度的数据产物，才可移除训练端为重算尺度而传递的 18 行历史前缀。

环境仍需在实际完整退出时锁存决策行的 `scale(t)`、实际成交均价及退出首次可见坐标；不能用返回观测行的 `scale(t+1)`，也不能随之后行情更新分母。浮亏率、退出时间和价格移动依赖策略轨迹，不能整体预计算到行情文件。十一维模型、replay/IPC 和加载契约的接入工作仍然需要完成。

初始化时可缓存固定配置和仓位归一化常量；完整退出时保存成交均价、首次可见步号和锁存尺度，之后只做差值、归一化和 tanh。实际仓位、持仓收益/回撤、浮亏、持仓时长、退出存在位与退出后变化仍动态维护；不新增全时点开平仓组合预计算表。本轮只同步文档，不实施代码。

### 5.2 流水线衔接与窗口有效性契约

- 计算位置固定在 Train/Valid/Test 分区已确定、同合约分区行序列已形成之后，训练 slice 切分之前；落点为 split-stage 的 scale-save 数据准备路径。不在跨分区完整行情上先计算再切分，也不在环境或每个训练 slice 中重新滚动。
- 价格输入固定使用环境 `current_markprice` 对应的原单位 `mark_price`，与第 4、5 节的 `P_t` 一致；不改用 `index_price`、成交价或标准化价格。
- scale-save 当前仅输出 reward/execution schema 与所选模型特征，新增行情辅助列必须有独立保留通道，继续贯穿 FineFT 合约数据、训练切片、标注切片及 worker 共享行情。不加入 RL/VAE 特征清单或 scaler，不改变三流市场输入维度。
- 窗口有效性应只由当前行及之前 18 行的合格价格决定；有效参考价须正且有限，缺列或异常价格明确失败，不能借窗口无效标记掩盖数据损坏。物理行不因本次预热被删除；环境依据完整窗口有效性选择可交易起点，老师表和 compact 索引保留原行情坐标。
- Q8 已确认采用 A：完整分区前 18 行的辅助统计值存为 0、布尔有效标记为 false，仅作不可消费的占位；有效恒价窗口存为 0、有效标记为 true。环境必须先验证有效标记，仅对有效行应用 `max(exit_price_scale_floor, statistic)`；禁止将无效占位通过尺度下限转为合格尺度。该约定是对“不用零填补完整窗口”的澄清，不以零伪造有效历史。不使用 NaN/空值表示预热不足，不为此放宽现有 NaN 检查；价格损坏或其他异常仍明确失败。

## 6. 最小状态与生命周期

每个环境实例新增 `last_long_exit_record`、`last_short_exit_record` 两个独立退出记录，各包含 `valid: bool`、`observation_step: int`、`execution_price: float`、`price_scale: float`。它们分别表示记录是否可用、退出首次可见的观测行、完成退出转移的成交均价、决策时锁存的价格尺度。表中 `last_long_exit_step/price/scale` 与空头对应记号分别引用该方向记录的后三个成员。记录保留执行数值精度，编码时才转 float32；不存在时数值字段规范为零，存在时 `price_scale` 必须为正。

| 场景 | 必须行为 |
|---|---|
| 新 episode、原地 reset、切换合约、Train/Valid/Test 隔离 | 清空两方向记录；不得读取前一 episode 的退出历史 |
| 初始有仓 | 沿现有初始化规则构造前 5 维；不能伪造此前退出记录 |
| 多头实际完全退出 | 只覆盖多头记录，保留空头记录 |
| 空头实际完全退出 | 只覆盖空头记录，保留多头记录 |
| 请求 Flat 但成交失败 | 不新增退出记录；已有记录保留；仍按实际持仓生成前 5 维 |
| 部分减仓 | 不登记完整退出；最终归零时取最后一次完成退出的转移成交均价，不混合此前部分减仓价格 |
| 重新开仓 | 保留两方向历史，新的完整退出才覆盖同方向记录 |
| 重复读取 info/构造 batch | 编码必须只读，不能重复登记事件或递增时长 |
| 换专家但仍处于同合约连续环境 | 保留退出记忆；切换模型不是 reset |
| 真实终止 | 在实际执行结果确定后完成退出记账，再构造终止观测；不得通过全零向量丢弃已有历史 |

终止路径可能留下执行前的 `env.position`。事件判定必须审计每个分支的最终执行结果，不能仅读取该属性，也不能只对普通 `change_of_wallet` 的第一次结果记账。若强平/终端处置没有输出成交数量与金额，补充该分支执行结果的可观测信息；不改成交规则，也不凭空制造成功退出。无成交证据时不得把“结束 episode”当作“已平仓”。

终止观测按最终实际执行结果编码全部 11 维；仍有仓位就保留真实持仓观测，并携带已有退出记忆。将终止路径原先返回的全零前 4 维改为真实观测，是四维回归的明确例外；奖励、实际成交、账户变化及终止判定继续保持原行为。

不新增直接反向开仓能力。当前执行语义下完整退出指实际从非零到零；若将来允许一步反手，应另行定义拆分成交事件，不能直接套本批规则。

## 7. 实施顺序与文件落点

任务拆分见 [实施依赖总览](implementation-plan.md)。保留 01–06 并新增 07（辅助列与坐标贯通）、08（环境观测与退出生命周期）；顺序为 `01 → 02 → 07 → 08 → 03 → (04、05) → 06`。01 保持四维运行基线；08 与 03 在同一集成变更中完成十一维运行切换，不将环境局部验收视为训练已可用。

### 7.1 字段契约与环境

建立唯一的字段顺序、`TRADING_INFO_DIM=11` 与 schema 标识，例如 `trading_state_input_v1`。schema 归属轻量契约模块，环境、模型和 replay 引用同一来源，避免模型为常量而导入重型环境模块。模块路径属于新增实现，不视为当前已有 API。

在 `base_env.py` 的初始化、reset、step 和全部终止分支维护事件；将“生成完全无历史零状态”和“编码当前空仓状态”区分开。18 步平均绝对价格变化由特征工程因果预计算，环境按 t 读取并应用配置下限；环境不重新扫描窗口，也不为此新增历史前缀传递。

检查 `commodity_env.py`、`demo_env.py` 的继承与覆写路径，以及 `env_initiate/` 中相关初始化入口；不要假定修改基类即可覆盖所有分支。输入出现 NaN/Inf、存在记录但时间位于未来、尺度非正时 Fail-fast，并给出字段、合约与行坐标。

### 7.2 模型、采集与 replay

- `FineFT/model/low_level.py`：Qnet、ensemble、两个模型重建辅助入口统一使用新维度；保持各独立输入及前向输出接口。
- `FineFT/RL/util/replay_buffer_DQN.py`：确认 n-step 的当前/终点 info 均完整保存 11 维，不把下一步强行当作 n-step 终点。
- `FineFT/RL/util/regime_stratified_replay_buffer.py`：调整 compact 声明、空数组、GPU 分配、批量入池、采样及导出；当前和 next 都覆盖。既有 float32 内容身份读取全部 11 项。
- `weight_advantage_pretrain.py`、`parallel_pretrain.py`、`parallel_weight_advantage_pretrain.py`、`parallel_diverse_train.py`：检查模型构造、真实 rollout、预训练 warmup、worker 参数与 learner update；当前/终点交易记忆必须来自轨迹实际历史，不能仅用行情坐标重建。
- compact IPC 继续传输交易向量；退出记录不需要作为精确执行快照传给 learner。它们保留在负责连续模拟的环境内。

### 7.3 评估、路由与产物

检查 `test_agent_index.py`、`test_agent_average.py`、`evaluate_sub_agents.py` 和 `vae_routing_util.py` 的加载与真实前向；对其他 Qnet/ensemble 调用者进行仓库搜索，处理共享模型构造默认值带来的影响。高层每个合约环境独立维护交易记忆，专家切换仅更换模型。

模型保存元数据包含 schema、字段有序列表、尺度窗口 18、时间饱和值 256、tanh 除数 5、实际 exit_price_scale_floor 配置值及其来源、实验覆盖说明与原持仓时长归一化参数。行情辅助产物还须记录统计量语义、窗口、价格单位和来源、合约及分区归属，并可验证与原始行坐标对齐；所有训练、评估和路由入口复用该数据契约。旧 4 维或原设计 18 维权重、replay 不得静默补零/截断后使用；加载前给出实际与期望维度。新规格需要重新训练匹配的模型，本次执行短程训练链路验证，正式重训另行开展。

裸 state_dict 至少检查 `fc_trading.weight` 输入宽度；宽度正确不等于字段语义相同，正式产物仍需 schema 元数据。`strict=False` 不能替代这种校验。

## 8. 老师、执行与既有决策的边界

旧 DP 老师只以旧状态条件产生标签。添加退出记忆后，同一旧状态可能出现不同新观测，但本批不会让老师标签因此变化。预训练可保持旧辅助监督流程作为明确标记的基线，不能宣称它是“新增交易记忆条件下的精确最优 Q”；新记忆能否通过 TD 学到增益须后续消融验证。

本批也不宣称完整消除了账户依赖：原收益/回撤、保证金约束和账户终止语义仍保留。若后续目标是资金充足、固定本金损益或统一执行约束，另立实施规格并对齐老师及训练语义。

与 [ADR-0002](../../docs/adr/0002-require-trading-info-qnet-input.md) 一致，交易输入必须显式传递，漏传不得静默补零。本文拟扩展 [ADR-0065](../../docs/adr/0065-n-step-discount-and-bounded-holding-context-replay.md) 中“四维上下文”的宽度为十一维，保留其去重与保留策略；代码实施时需同步修订该维度描述。本次不修改已接受 ADR。

[ADR-0045](../../docs/adr/0045-high-level-vae-routing-action-persistence-with-defensive-preemption.md) 与 [ADR-0047](../../docs/adr/0047-contract-level-hard-stop-loss-cooldown-and-circuit-breaker.md) 的现有高层控制行为不因本批输入升级而被删除或重定义。11 维未呈现这些全部外层控制状态，这是本批范围限制。

## 9. 验收标准

| 验收项 | 必须证明 |
|---|---|
| 四维回归 | 相同固定动作与行情下，普通观测前 4 维逐步等于旧实现；终止观测由全零改为真实持仓编码是明确例外。奖励、实际成交、账户变化和终止判定保持原行为 |
| 浮亏率 | 空仓不除零；盈利为 0；亏损与既有止损率一致；多空、非单位仓位均覆盖 |
| 退出记忆 | 无历史空仓与刚退出不同；多空记录不互相覆盖；重新入场保留历史 |
| 成交事实 | 拒绝平仓不写事件；部分减仓不写完整退出；实际归零只写一次；使用成交均价 |
| 时间与因果性 | 退出首个返回观测间隔为 0，下一步为 1/256；价格变化可非零；修改未来行情不改变当前输入 |
| 尺度 | 特征工程仅用截至当前行的 19 个价格；辅助列不被筛选或标准化；恒价统计量为零、环境用尺度下限保底；缺列、非法值、缺尺度下限或无完整窗口明确失败；切片不重复预热；退出后尺度不漂移 |
| 窗口有效性 | 分区前 18 行为 0/false、不可交易；有效恒价窗口为 0/true、使用配置下限；无效占位不得进入交易或 replay；保留物理行、老师表和 compact 坐标对齐，不放宽 NaN 检查 |
| 边界与隔离 | 256 步饱和但记录仍在；reset、跨合约、分区不串记忆；同合约专家切换保留记忆；终止分支不全量清零 |
| 模型 | 真实 Qnet/ensemble 前向接受 `(B,11)`；用确定性权重证明新增维度能影响输出，不能只改测试长度 |
| replay/IPC | 完整与 compact 路径当前/next 向量一致，覆盖空批次、满窗及短窗 n-step；CPU/GPU 可用路径均验证 |
| 既有去重 | 同行情、动作、原四维相同而退出记忆不同的记录不合并；四后续上限与 FIFO/随机轮换语义不变 |
| 集成 | 预训练、多样化训练、按索引评估、路由各有短程真实环境与模型 smoke test；用合成新维度权重即可，无需正式重训 |
| 短程训练 | 真实环境生成 11 维轨迹，经 replay 入池与采样后送入真实 learner 更新；证明损失有限且模型参数实际更新，并验证新增字段可影响模型输出。短程验证不作为收益结论 |
| 错误处理 | 漏传、4/18 维输入、不符 schema、非有限数值、非法历史时间明确失败 |

优先扩展现有测试：`FineFT/tests/env/test_trading_process_features.py`、`test_position_cost_state.py`；`FineFT/tests/rl/test_qnet_trading_info.py`、`test_replay_buffer_trading_info.py`、`test_compact_trajectory_and_micro_batched_ingestion.py`、`test_learning_targets_and_bounded_replay.py`、`test_test_agent_index.py`。涉及止损和路由的测试用于证明原执行行为未被输入改造改变。

实施验证使用项目要求的 `conda activate finetf` 环境执行 Python/pytest。以上为实现完成后的验收要求；当前仍处于设计讨论阶段，尚未运行训练或声称测试通过。

## 10. 完成定义

只有在环境能真实产生十一维输入、全部消费和传输路径一致、旧 schema 明确拒绝、上述验收通过后，才能标记“第一批交易 state 输入已实施”。正式收益增益、完整状态老师、资金无关教学环境和统一执行状态机均不属于该完成声明。
