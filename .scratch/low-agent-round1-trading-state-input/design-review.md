# 交易状态输入设计讨论

日期：2026-11-01
状态：未实施；用户已回退本功能全部代码改动。既有逐项决策保留，尺度计算边界已确认，本轮仅同步文档。

## 已确认决策

用户确认第一轮 Q1–Q3 全部采用推荐项：

1. 完成目标为设计确认后的代码接入、测试与短程训练验证。短程验证包含真实环境采集、replay、模型前向与参数更新；正式重训不在本次目标内。
2. 采用 spec 的 11 维交易观测：原有 4 维、浮亏率 1 维及双方向退出记忆 6 维。退出记忆的收益价值仍是待验证假设；后续建议以 4/5/11 维对照检验，本次不据此宣称收益提升。
3. 旧 DP 老师保留为辅助监督基线，不扩展教师状态或重算标签。旧标签不针对新增退出记忆给出不同答案；新增记忆的价值依赖后续 TD 学习与验证。
4. Q4 的历史前缀方案已被本轮预计算方案取代：在同合约、同分区内先计算完整窗口统计量，再切训练片段；分区首部历史不足行不可交易，随机切片不重复丢弃前 18 行。保留行情与老师坐标，对照实验统一起点，预热不模拟交易。
5. Q5 采用推荐：终止观测按最终实际执行结果编码全部 11 维，仍持仓时保留持仓观测，仅真实完整退出更新退出记忆。终止路径由全零改为真实观测是前四维回归的明确例外；奖励、成交和终止判定沿用现有行为。
6. 用户要求 exit_price_scale_floor 做成可配置命令行参数，贯穿环境及 worker。Q7 已确认按推荐：本次 fu 实验使用 `--exit_price_scale_floor 5`，作为价格尺度下限覆盖值；交易所最小变动价位 1 元/吨单独记录，不把实验值 5 描述成交易所规格。配置及产物记录实际值、来源和覆盖说明。

## 已核实事实

- 模型和部分 replay 路径当前仍为 4 维；部分采集路径存在漏传时补零的逻辑。
- 普通执行结果包含实际关闭数量和成交金额，可计算完整退出成交均价。
- 当前环境尚无 `exit_price_scale_floor` 接口；需新增配置传递。行情统计按已确认方案在特征工程预计算，不为尺度重算新增历史前缀传递。
- 终止路径返回全零交易观测；数据尾部终止本身没有独立平仓成交证据。
- 现有测试有足够长度的合成行情和真实 learner update 测试，可扩展为真实环境对象的短程采集、replay 与更新验证；合成行情验证不代表真实历史收益验证。
- 当前 checkpoint 主要保存裸 state_dict，尚无输入 schema 元数据契约；实现需新增元数据保存与加载校验。smoke 中可显式注入合成老师表，避免触发整段行情 DP 计算。

Q1–Q7 设计分支已逐项确认，现有规格已覆盖剩余生命周期、因果性、传输及兼容性要求。此前代码改动已全部回退，旧实施及测试记录不再构成当前完成证据。用户已确认行情统计预计算、交易状态动态维护；规格与实施票已同步，本次只维护文档。

原 spec 的历史任务描述不替代本次用户确认的工作范围。逐项设计确认不等同于已经实现或测试通过。

## 回退后重新讨论（2026-11-01）

- 当前环境、Qnet 仍为四维；01–06 票均恢复为未实施、验收项未完成，状态已在本轮设计同步后更新为 `ready-for-agent`，仍须按依赖顺序实施。
- ADR-0065 恢复四维基线；十一维扩展仍由本 spec 提议，不记为已落地契约。词汇表保留领域含义，不能据此推断实现状态。
- `scale(t)` 可因果预计算；推荐预计算原价格单位的 18 步平均绝对变化，环境按实验下限取 max 并在退出时锁存。也可预计算最终尺度，但下限配置将成为数据产物契约的一部分。用户已确认采用预计算变化统计量、环境应用配置下限的方案，见 spec 5.1。
- 重新讨论只涉及计算位置和配置归属，既有窗口长度、退出锁存时点、分区隔离及随机切片起点原则暂不改动。

### 本轮确认结果

行情侧预计算 18 步平均绝对价格变化及完整窗口有效性，保留价格单位、合约/分区边界与行坐标；环境应用实验下限，退出时缓存事件及锁存尺度。其余交易观测动态维护；初始化缓存常量，不预计算所有开平仓组合。所有票保持未实施、验收项未完成；本轮不启动代码修改。

### 尺度下限命名确认

用户确认将实验尺度下限由原设计名 `tick_size` 改为 `exit_price_scale_floor`，命令行使用 `--exit_price_scale_floor 5`。交易所最小变动价位与该实验参数独立；回退前历史记录中的旧参数名原样保留，不作为新实施接口。

### 衔接审计与 Q8（已确认 A）

源码事实：`muti_contract_scale_save.py` 的输出仅包含 reward/execution schema 与所选市场特征，辅助列需要独立保留通道；输入输出均调用全表 NaN 检查。分区后的 scale-save 路径适合计算统计量，后续 FineFT 切片可继承已计算列。规格已明确使用原单位 mark_price，不新增 index_price 口径，不物理删除预热行。

Q8 用户已确认采用 A：前 18 个无完整窗口的行统计量写 0、布尔有效位 false；有效恒价窗口写 0、有效位 true。环境先验证有效位，仅对有效行应用尺度下限；无效占位不得被转为合格尺度。保留物理行与索引对齐，不使用 NaN/空值表示预热不足，不放宽现有 NaN 检查。02 票恢复 ready-for-agent，原依赖关系保留；全部功能仍未实施，本轮只同步文档。
