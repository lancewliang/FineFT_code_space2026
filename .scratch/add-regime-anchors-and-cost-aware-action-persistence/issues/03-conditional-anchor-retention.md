# 03: 按跨合约稳定性条件保留市场状态锚点

**What to build:** 让 Feature Selection 能保留在低波动强方向目标格中稳定有效、但全局平均指标不足的市场状态锚点，同时保持普通 candidate State Feature 的原有筛选行为。

**Blocked by:** 02: 发布 train-only 16 格条件市场状态审计。

**Status:** ready-for-agent

- [ ] 条件规则仅作用于声明的市场状态锚点，目标格为波动率格 0/1 与斜率格 0/3 的四个组合。
- [ ] 每合约至少 30 个对齐步骤、至少 3 个合约、非零 RankIC 符号一致率至少 60%，且一致方向 RankIC 的 90% 单侧下置信界不低于 `min_abs_ic` 时，锚点才可补充保留。
- [ ] Manifest 记录条件保留原因、通过格、门槛和最终稳定特征顺序。
- [ ] 空格、样本不足、合约不足、符号不稳定或置信界不足时不补充保留，但不阻断其他筛选。
- [ ] 关闭条件选择或读取旧配置时，最终特征和旧行为保持兼容。
- [ ] focused tests 覆盖通过/不通过边界、普通候选不可被条件规则救回、valid report-only 和旧配置回归。
