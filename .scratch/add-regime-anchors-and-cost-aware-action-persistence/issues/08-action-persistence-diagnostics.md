# 08: 发布动作迟滞逐步诊断与汇总

**What to build:** 让训练日志和逐步交易明细能够解释每一次候选换仓是执行还是被成本迟滞抑制，并量化减少的换仓与预计执行成本。

**Blocked by:** 07: 端到端启用成本感知动作迟滞。

**Status:** ready-for-agent

- [ ] 每个模型贪心决策记录当前动作、原始候选、最终动作、Q 优势、预计成本、门槛和决策原因。
- [ ] 汇总记录候选换仓数、实际换仓数、被抑制换仓数和估计避免成本。
- [ ] 诊断字段不改变既有交易明细字段语义，并能在迟滞关闭时正常输出兼容结果。
- [ ] focused tests 验证执行、保持、风险绕过和随机探索不计入错误类别。
