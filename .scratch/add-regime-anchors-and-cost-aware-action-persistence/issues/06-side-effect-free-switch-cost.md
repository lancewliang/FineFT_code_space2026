# 06: 提供无副作用的逐动作预计换仓成本

**What to build:** 让 Futures Trading Environment 在每个决策时点提供与真实执行语义一致的逐动作预计手续费和不利滑点，供共享动作选择规则判断是否值得换仓。

**Blocked by:** 05: 迁移路由后的 Low-level 动作消费者。

**Status:** ready-for-agent

- [ ] 逐可用动作输出当前仓位/杠杆切换的非负预计成本；保持当前动作成本为零。
- [ ] 估算复用盘口深度、手续费率、深度截断、保证金和 Reverse Position best-effort 语义。
- [ ] 不可用动作不参与成本候选；非有限输入和不合法状态 Fail-fast。
- [ ] 估算不得修改钱包、仓位、杠杆、累计费用、持仓历史或随机状态。
- [ ] focused tests 将估算结果与同状态实际执行结果配对比较，覆盖开平仓、加减仓、反手、深度不足和反手开关。
