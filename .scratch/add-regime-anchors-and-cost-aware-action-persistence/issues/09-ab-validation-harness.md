# 09: 建立三组消融与 16 格评估流水线

**What to build:** 提供可重复的 A/B/C 离线评估：A 为现有基线，B 为锚点+条件选择，C 为 B+成本迟滞；结果能按全部 16 格和目标四格归因。

**Blocked by:** 08: 发布动作迟滞逐步诊断与汇总。

**Status:** ready-for-agent

- [ ] 固定数据切分、随机种子、epoch/checkpoint 候选和执行费用配置，生成三组可比较实验。
- [ ] 每组报告全部 16 格及目标四格的步骤数、净收益、换仓次数/率、手续费、滑点和最大回撤。
- [ ] 报告提供按合约或片段配对 bootstrap 的差值置信区间，并区分 train 与 valid。
- [ ] 小规模 fixture 可以独立运行并验证报告结构、格计数守恒和配置隔离。
- [ ] 评估流水线不读取或调参 test，不覆盖现有基线产物。
