# 07: 端到端启用成本感知动作迟滞

**What to build:** 让共享动作选择规则在 Q 优势不足以覆盖预计换仓成本和安全边际时保持当前仓位，并在训练与全部 Low-level 推理消费者中一致生效。

**Blocked by:** 06: 提供无副作用的逐动作预计换仓成本。

**Status:** ready-for-agent

- [ ] 仅当 `Q(candidate) - Q(current)` 严格大于成本倍数×预计成本+安全边际时才换仓，否则保持当前动作。
- [ ] 当前动作不可用或环境要求风险处置时，风险动作优先，不得保持不可用动作。
- [ ] 错误初始仓位仍可平仓或换向，不引入固定最短持仓时间。
- [ ] epsilon 随机探索、固定风格 rollout 和 DP expert path 不应用迟滞。
- [ ] 开关、成本倍数和安全边际非负且持久化；缺少配置的旧模型默认关闭；显式不一致时 Fail-fast。
- [ ] focused tests 覆盖小于/等于/大于门槛、同动作、当前动作不可用、风险优先、反手和旧配置回归。
