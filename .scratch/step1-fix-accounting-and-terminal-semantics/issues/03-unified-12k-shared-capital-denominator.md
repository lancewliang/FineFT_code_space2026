# 03: 统一 12,000 共享组合资金分母与单合约除零消除 (Unified 12k Shared Capital & Zero-Denominator Elimination)

**What to build:** 在单合约结果统计、超参搜索评估目标以及组合诊断中，全链路统一使用固定的 12,000 元共享组合初始本金。彻底消除未交易合约动态资金需求为零导致的除零收益率异常，移除搜索阶段依赖活跃合约数动态缩放分母的逻辑，使搜索优化目标与最终时间同步组合回放指标在同一分母下完全对齐。

**Blocked by:** 01: 终局边界语义解耦与 ADR-0060 正式确立 (Terminal Boundary Decoupling & ADR-0060 Adoption), 02: 真实成交执行快照与订单级审计对账修复 (Real Execution Snapshot & Trade Audit Conservation)

**Status:** ready-for-agent

- [ ] 共享组合本金常数全链路统一定为 12,000 元（对应双主力并发配资）
- [ ] 单合约结果表中彻底消除除以接近 0 的资金需求异常，无 10^13~10^15 极端收益率
- [ ] 超参搜索阶段单次 Trial 收益率基于时间戳对齐后的组合逐步 PnL 与 12,000 本金计算
- [ ] 相同参数下搜索阶段计算出的 TR 与 MDD 和最终组合回放计算值完全一致
- [ ] 组合报告与单合约报告的本金、净利润与收益率口径清晰一致，无多套本金展示混用
