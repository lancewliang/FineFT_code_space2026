# 03 — 补全策略二阶形态分类器

**What to build:** 在已确定的行情事件语义上完成 6 类策略二阶形态，使分类器根据已执行仓位与行情的关系返回所有兼容形态。

**Blocked by:** 02 — 补全 K 线形态分类器

**Status:** ready-for-agent

- [ ] 所有仓位判定消费 sidecar 的完整有序 signed position 档位，不从单条行为轨迹反推动作空间。
- [ ] 完成 ST2 回调加仓事件链：突破、回踩、当步或下一步同向加仓、最终再延续；ST2 不要求加仓前盈利。
- [ ] 完成 ST3 盈利后同向加仓，排除开仓、减仓、反手以及加仓前浮动 PnL 非正的事件。
- [ ] 完成 SM1 普通 Z-score 硬边界和涨跌停语义下的逆向近满仓开/加仓，排除仅持有、顺势、减仓、平仓和反手。
- [ ] 完成 SM2 高位向空头相邻档位和低位向多头相邻档位的有序反向调仓对，允许经过零档，排除跨多档和直接反手。
- [ ] 完成 SM3 背离过滤：背离段不沿突破方向开/加仓，且非背离段至少存在一次有效仓位变化。
- [ ] 各策略规则独立判定并允许兼容多选，包括同窗 ST2+ST3。
- [ ] 同一背离突破事件不得同时归因 ST1 与 SM3；仅不同合格事件可使两者同窗共存。
- [ ] 普通 20 步窗口运行全部规则；涨跌停窗口严格执行各规则最小样本数，样本不足时不补齐或外推。
- [ ] 所有可运行规则均不命中时返回策略未分类诊断哨兵，不丢弃窗口。
- [ ] 至少使用两组动作空间参数化测试，覆盖 6 类、多选、冲突、多空对称、短轨迹、未分类和阈值边界。
