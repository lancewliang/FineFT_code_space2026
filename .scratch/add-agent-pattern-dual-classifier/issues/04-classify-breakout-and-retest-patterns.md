# 04 — 贯通突破与回踩形态

**What to build:** 在现有窗口数据路径上实现突破与回踩行情及其对应 Agent 策略，使 KT1、KT2、ST1 和 ST2 从纯函数判定贯通到 Window 和 Expanded tables，并能在真实行为窗口中追溯事件时序和仓位变化。

**Blocked by:** 03 — 生成窗口身份、PnL 和基础分析表。

**Status:** ready-for-agent

- [ ] KT1 只在规定的突破检测区间触发，并满足最终延伸和突破侧保持比例。
- [ ] KT2 严格执行突破、新极值、回踩、重新延伸顺序，突破触发点不得充当回踩点。
- [ ] ST1 只识别突破当步或下一步的空仓到近满仓同向开仓，并正确计算后续同号持仓观测。
- [ ] ST2 要求突破、回踩、同向加仓和再次延伸的完整事件链。
- [ ] 所有规则在上涨和下跌方向对称，并使用参数化阈值与共享 Position Level。
- [ ] K 线单选优先级确保 KT2 优先于通用 KT1。
- [ ] 合成测试覆盖四种正式形态、缺少任一事件、时序错误、多空对称及阈值边界。
- [ ] 端到端测试证明命中结果进入固定 Window/Expanded schema，窗口 PnL 仍只保存一次。
