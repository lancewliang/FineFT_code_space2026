# 06 — 贯通反转、箱体与网格调仓形态

**What to build:** 扩展同一窗口分类路径以识别 V/倒V、箱体、硬边界反转和离散网格调仓，使 KM1、KM2、SM1 和 SM2 能在不同动作空间中保持一致的多空对称语义。

**Blocked by:** 05 — 贯通加速与盈利后加仓形态。

**Status:** ready-for-agent

- [ ] KM1 使用参数化 z-score、双腿最小收益和最小边长识别 V/倒V，排除端点极值和不完整双腿。
- [ ] KM2 使用 log-return 波动率、上下沿触达和压缩后的最小状态转换次数识别箱体。
- [ ] SM1 在普通窗口使用硬 z-price 边界，在涨跌停事件窗口使用 Label 极端方向，且只接受逆向近满仓开仓或加仓。
- [ ] SM2 要求时间有序的高位向空头相邻档位移动与低位向多头相邻档位移动，不要求最终回到初始档位。
- [ ] 跨多档跳仓、直接反手、单侧调节、仅持有、减仓和平仓满足相应排除规则。
- [ ] z-price 使用完整窗口均值与 `ddof=0` 标准差；零方差时相关规则不命中。
- [ ] 至少两套 Position Level 参数化测试证明近满仓、相邻档位和同向动作没有写死。
- [ ] 四类形态的结果进入固定 Window/Expanded schema，未命中窗口继续保留哨兵。
