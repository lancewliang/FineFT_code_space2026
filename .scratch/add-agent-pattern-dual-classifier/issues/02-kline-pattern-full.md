# 02 — 补全 K 线形态分类器

**What to build:** 在已验证的纯函数 seam 上完成 7 类 K 线形态和未分类语义，使每个窗口以确定优先级返回恰好一个行情侧形态。

**Blocked by:** 01 — KT1/ST1 可信数据 tracer bullet

**Status:** ready-for-agent

- [ ] 实现 KT2 突破—新极值—回踩—再延续的严格事件链，突破触发点不可同时充当回踩点。
- [ ] 实现 KT3 前后半窗 log-price 斜率同向加速规则，并对多空方向对称。
- [ ] 实现 KM1 V/倒V 反转，校验极值 Z-score、两腿反向、最小幅度和最小边长。
- [ ] 实现 KM2 箱体，同时约束 log-return 波动率、均价外沿、触边区和压缩后的上下沿转换数。
- [ ] 实现 KM3/SM3 可共用的价格—成交量背离事件检测，覆盖基准期、突破幅度、突破附近 volume 中位数下降和最小价格移动。
- [ ] KX1 仅由涨跌停 Label 决定，不进入普通窗口规则竞争。
- [ ] 所有 Z-score 规则使用完整窗口、`ddof=0`；价格零方差时所有依赖 Z-score 的规则均不命中。
- [ ] 实施 `KX1 → KM1 → KT2 → KM3 → KT1 → KT3 → KM2 → 未分类` 优先级，每窗口始终只输出一个 K 线形态。
- [ ] 阈值通过配置/fixture 注入，标定后不需改变测试结构。
- [ ] 合成行为测试覆盖全部形态、多空对称、优先级冲突、未分类和每个阈值的上下边界。
