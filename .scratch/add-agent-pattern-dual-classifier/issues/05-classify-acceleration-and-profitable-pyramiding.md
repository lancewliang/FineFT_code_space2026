# 05 — 贯通加速与盈利后加仓形态

**What to build:** 在已建立的突破/回踩分类路径上加入趋势加速和盈利后同向加仓，使 KT3 与 ST3 可在同一窗口分析契约中稳定识别，并支持与 ST2 的兼容多选。

**Blocked by:** 04 — 贯通突破与回踩形态。

**Status:** ready-for-agent

- [ ] KT3 使用窗口前后半段 log-price 斜率识别同向加速，并要求累计收益达到参数化阈值。
- [ ] 匀速趋势、前后斜率反向、加速倍数不足或累计收益不足不得命中 KT3。
- [ ] ST3 只识别执行前后仓位同号、绝对仓位增加且加仓前浮动 PnL 大于零的事件。
- [ ] 开仓、减仓、平仓、反手和非盈利加仓不得命中 ST3。
- [ ] ST3 对多头和空头对称，并从共享 Position Level 判断同向风险增加。
- [ ] 同一回踩加仓事件满足盈利前提时，策略数组可以同时包含 ST2 和 ST3。
- [ ] 合成测试覆盖 KT3/ST3 正反例、多空对称、阈值边界和 ST2+ST3 多选。
- [ ] Window 与 Expanded tables 对多选窗口仍保持唯一 Window PnL。
